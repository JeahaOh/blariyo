## 제외 범위

- M0 수집 보조·자동 수집과 collector. M1.5는 `design/m0-collection-assist/v1`을 요구하지 않는다.
- 뉴스·추가 게시판, 추천·비추천·랭킹·쪽지·팔로우·알림·대댓글.
- 익게 이미지 업로드, 광고·제휴 활성화, 자동 moderation·신고 수 자동 제재.
- 탈퇴 시 콘텐츠 전체 삭제 선택과 탈퇴한 글·댓글의 자동 삭제·복원.

## 남은 gate와 미검증

- M1 구현·공개 선행 gate, M1.5 약관 법무 검토·시행일, 신고 설명·운영 메모 90일과 삭제 ledger 8주의
  처리 근거·기간, 이의제기 이메일·운영자 moderation 수용이 필요하다.
- source·migration·OpenAPI·test·build·PostgreSQL constraint/경쟁·탈퇴 worker·UI/browser·관리자 runtime은
  미구현·미검증이다.
- 글별 랜덤 이름 사전의 262,144조합 기계 검사는 설계 모델 증거이며 전체 문구별 사람 검수나 실제 DB
  배정 경쟁 검증이 아니다.
- 탈퇴 KEEP, 같은 글 이름 고정·다른 글 변경과 ACTIVE 제재 predicate를 법무 적정성·운영 완료로 해석하지 않는다.
