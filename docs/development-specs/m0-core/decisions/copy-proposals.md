# M0 Core 카피안

- 문서 상태: OD-M0-013 확정안
- 대상 결정: [OD-M0-013](./open-decisions.md)
- 기준 문서: [카피 후보](../../../planning/06-copy-candidates.md), [화면 설계](../../../planning/03-screen-design.md)
- 작성일: 2026-09-03

## 1. 목적

홈, 검색·공유 미리보기, 푸터 브랜드 문구에 사용할 M0 Core 카피 확정안을 기록한다.

이 문서는 [open decisions](./open-decisions.md)의 OD-M0-013 확정 근거다. 카피를 실제 화면과
설정 문서에 반영할 때는 이 문서의 값과 properties/config key를 기준으로 동기화한다.

## 2. 판단 기준

- 디시인사이드, 에펨코리아, 뽐뿌, 클리앙, 인벤, 오늘의유머, 보배드림, MLBPARK, 개드립,
  더쿠, 인스티즈, 네이트판, 아카라이브, 웃긴대학, 루리웹, 고급유머, 이토랜드처럼 이름 자체를
  중심에 두고 설명은 짧게 붙인다.
- 메인 문구는 과장하지 않는다.
- 유행어, 말장난, 감탄사, 과한 행동 유도는 쓰지 않는다.
- 첫 화면에서 `여기가 무엇을 보는 곳인지`만 바로 알 수 있으면 된다.
- 카카오톡, X/Twitter, 메신저 미리보기에서 잘려도 의미가 남아야 한다.
- 출퇴근·통학 맥락은 운영 전략과 발행 시간에는 남기되, 서비스 대표 카피에 과하게 넣지 않는다.
- 참고 사이트 조사: [커뮤니티 사이트 카피·타이틀 조사](./reference-site-copy-research.md)

## 3. 확정안

| 적용 위치 | 추천 카피 |
| --- | --- |
| 메인 슬로건 | 블라리요 |
| 홈 보조 문구 | 블라블라블라 |
| 홈 `<title>` | 블라리요 - 블라블라블라 |
| 홈 `description` | 블라리요에서 블라블라블라 |
| 홈 `og:title` | 블라리요 |
| 홈 `og:description` | 블라리요에서 블라블라블라 |
| 푸터 브랜드 한 줄 설명 | 블라블라블라 |

## 4. 추천 이유

커뮤니티 계열 서비스는 대표 카피가 길지 않다. 이름이 먼저 보이고, 설명은 게시판 성격을 구분할
정도로만 붙는다. 사용자가 제시한 참고 서비스들도 대체로 강한 슬로건보다 서비스명, 게시판명,
짧은 설명, 현재 글 목록이 중심이다.

- `블라리요`를 메인에 단독으로 둬 브랜드명을 먼저 남긴다.
- `블라블라블라`는 서비스명과 어감이 맞고, 과장 없이 느슨한 커뮤니티 분위기를 만든다.
- SEO와 공유 metadata도 `블라리요/블라블라` 맥락으로 맞춘다.
- `출퇴근길`, `한 정거장`, `짧게 보고 웃고 가는` 같은 문구는 설명이 길고 캠페인 느낌이 난다.
- `유머`보다 `웃긴 글과 짤`이 실제 콘텐츠와 더 가깝고 덜 포장돼 보인다.
- 푸터도 `블라블라블라`로 두어 화면 전체의 말투를 통일한다.

광고 차단 안내는 [서비스 기획](../../../planning/01-service-plan.md)과 퍼블리싱 프로토타입에 별도 항목이
있지만, OD-M0-013의 홈·상세·공유 카피 확정 범위에서는 제외한다.

단점은 검색·공유 미리보기에서 서비스 성격 설명이 약해질 수 있다는 점이다. 다만 M0에서는 실제
게시판·글 목록이 성격을 보완하고, 과한 설명형 문구보다 이름과 톤을 먼저 고정하는 쪽이 낫다.

## 6. Properties 관리 설계

위 카피는 source에 하드코딩하지 않고 배포 환경 properties/config로 주입한다. 문구는 비밀값이 아니므로
public runtime config로 내려보낼 수 있지만, 변경 이력은 배포 설정에서 관리한다.

권장 key는 다음과 같다.

| key | 값 | 사용 위치 |
| --- | --- | --- |
| `NUXT_PUBLIC_SITE_NAME` | `블라리요` | 홈 메인, `og:title`, site name |
| `NUXT_PUBLIC_HOME_TAGLINE` | `블라블라블라` | 홈 보조 문구 |
| `NUXT_PUBLIC_HOME_TITLE` | `블라리요 - 블라블라블라` | 홈 `<title>` |
| `NUXT_PUBLIC_HOME_DESCRIPTION` | `블라리요에서 블라블라블라` | 홈 `description` |
| `NUXT_PUBLIC_HOME_OG_DESCRIPTION` | `블라리요에서 블라블라블라` | 홈 `og:description` |
| `NUXT_PUBLIC_FOOTER_TAGLINE` | `블라블라블라` | 푸터 브랜드 한 줄 |

운영 규칙:

- 기본값은 코드에 fallback으로 둘 수 있지만, production은 properties/config 값 주입을 기준으로 한다.
- 빈 문자열은 허용하지 않는다. 누락되면 build 또는 startup에서 실패시키는 쪽이 낫다.
- 게시글 상세 title·description은 게시글 제목과 OD-M0-008 본문 요약 규칙을 우선한다.
- 상세에 본문 TEXT가 없어 fallback이 필요할 때만 `NUXT_PUBLIC_HOME_OG_DESCRIPTION`을 사용할 수 있다.
- 광고 차단 안내 문구는 이 key 묶음에 넣지 않는다. 광고 정책/화면 문구에서 별도 관리한다.

## 7. 제외안

이전 R1~R5와 기존 A~E 후보는 최종안 후보에서 제외한다.

| 제외안 | 제외 이유 |
| --- | --- |
| A `출퇴근길엔 블라리요` | 맥락은 맞지만 설명적이고 평이함 |
| B `오가는 길에 웃고 가요` | 자연스럽지만 브랜드 기억이 약함 |
| C `한 정거장 웃고 가요` | 짧은 소비 맥락은 좋지만 서비스명이 빠짐 |
| D `가는 길에 하나만 더` | 연속 소비 느낌은 좋지만 첫 화면 대표 문구로 약함 |
| E `퇴근길에 웃을 거리` | 퇴근길에 치우쳐 출근·통학 맥락이 빠짐 |
| R1 `볼라리요? 블라리요.` | 말장난이 강하고 커뮤니티 서비스 톤보다 캠페인 문구에 가까움 |
| R2 `오늘 볼 짤, 블라리요` | 기능은 보이지만 문구형 느낌이 남음 |
| R3 `한 정거장만 보고 가요` | 이동 맥락이 과하게 앞서고 브랜드명이 빠짐 |
| R4 `심심할 땐 블라리요` | 흔하고 평범함 |
| R5 `내리기 전에 하나만 더` | 행동 유도 문구라 서비스 대표 문구로 약함 |
