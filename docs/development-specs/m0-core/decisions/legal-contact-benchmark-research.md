- 문서 상태: OD-M0-006 법무·문의 정보 관리 방식 확정 참고 조사
- 대상 결정: [OD-M0-006](./open-decisions.md)
- 관련 문서: [법무 README](../../../legal/README.md), [개인정보처리방침](../../../legal/privacy-policy.md), [권리자 요청 안내](../../../legal/rights-request.md)
- 확인일: 2026-09-03
- 정정일: 2026-09-04 (고급유머 기준 URL)
- 보존 범위: 사이트 관측·법무 판단 후보·config 이름은 9월 3~4일 참고 조사다. 2026-09-24에 원문과 현행 정본 연결을 검토했으며 외부 사이트나 법적 의무를 새로 확인한 결과가 아니다. 현재 M0 발행 상태와 실제 앱 입력은 [운영 실값 체크리스트](operational-values-checklist.md)와 [공개 정책](../../../legal/m0-core/README.md)을 따른다.

## 1. 목적

국내 커뮤니티·유머 사이트가 푸터, 이용약관, 개인정보처리방침, 게시중단·문의 진입점에
운영자·사업자·연락처 정보를 어떻게 표시하는지 확인한다.

이 문서는 벤치마크 참고 자료다. 실제 법무 의무 판단과 블라리요의 확정 법률 문구는
`docs/legal/` 정본에서 별도로 확정한다.

## 2. 조사 요약

참고 사이트는 크게 두 유형으로 나뉜다.

| 유형 | 사이트 예 | 표시 패턴 |
| --- | --- | --- |
| 법인·사업자형 | 디시인사이드, 인벤, 보배드림, 웃긴대학, 인스티즈, 네이트판/동아 계열 | 회사명, 사업자등록번호, 통신판매업신고번호, 대표자, 주소, 전화·팩스, 개인정보 보호책임자 등을 푸터 또는 개인정보처리방침에 노출 |
| 개인·커뮤니티 운영형에 가까운 형태 | 개드립, 더쿠, 디미토리, 이토랜드 일부 | 사업자 정보 노출은 약하거나 제한적이고, 이용약관·개인정보처리방침·문의 이메일·신고/게시중단 진입점 중심 |

블라리요 M0는 사업체 여부가 확정되지 않았으므로, 사업자 풀세트 표시보다
`문의`, `권리 문의`, `개인정보 문의/담당자`를 먼저 확정하고 properties/config로 관리한다.

## 4. 블라리요 적용 판단

블라리요가 사업자등록 전 개인 운영 또는 비사업 운영 상태라면, 보배드림·인벤·웃긴대학처럼
사업자 정보를 모두 표시하는 구조는 현재 단계에 과하다.

M0 Core에는 다음 기준을 적용한다.

| 구분 | M0 권장 상태 | 이유 |
| --- | --- | --- |
| 운영자 표시명 | 필요 | 약관, 개인정보처리방침, 권리 요청의 책임 주체가 필요 |
| 일반 문의 이메일 | 필요 | 이용약관·운영 문의 접수 채널 |
| 권리 침해 신고/요청 이메일 | 필요 | 외부 콘텐츠 출처·권리 대응이 M0 핵심 리스크 |
| 개인정보 문의 이메일 | 필요 | 개인정보 처리방침과 정보주체 권리 행사 채널 |
| 개인정보 보호책임자 또는 담당자 | 필요 | 개인정보를 처리하는 서비스의 기본 고지 항목 |
| 사업자명·사업자등록번호 | 사업자등록 전 보류 | 사업자가 아니면 추정값으로 채우지 않음 |
| 대표자명 | 사업자/법인 전환 전 보류 또는 운영자명 대체 검토 | 법인·사업자 표시와 개인정보 최종 책임자 성격이 섞임 |
| 주소·전화번호 | 법무 검토 전 보류 | 개인 운영자의 실주소·전화번호 공개 리스크가 큼 |
| 통신판매업신고번호 | 거래·결제 기능 전 보류 | M0 공개 열람 중심이면 즉시 확정 대상이 아님 |

## 5. properties/config 관리안

아래는 초기 제안 이름이며 현재 배포 입력 목록이 아니다. 앱이 실제 사용하는 `NUXT_PUBLIC_*`와 Core `LEGAL_CONFIG` 매핑은 운영 실값 체크리스트를 적용한다.

실제 값은 문서와 source에 하드코딩하지 않고 배포 환경 properties/config에서 주입한다.
공개 페이지에 노출되는 값이지만, 실명·주소·전화번호는 변경과 보호 필요성이 있으므로 Git에
실값을 커밋하지 않는다.

```properties
BLARIYO_OPERATOR_DISPLAY_NAME=(미정)
BLARIYO_GENERAL_CONTACT_EMAIL=(미정)
BLARIYO_RIGHTS_CONTACT_EMAIL=(미정)
BLARIYO_PRIVACY_CONTACT_EMAIL=(미정)
BLARIYO_PRIVACY_OFFICER_NAME=(미정)
BLARIYO_PRIVACY_OFFICER_TITLE=(미정)
BLARIYO_PRIVACY_DEPARTMENT=(미정)

# 사업자 등록 또는 거래 기능 확정 후 사용
BLARIYO_BUSINESS_NAME=(미정)
BLARIYO_REPRESENTATIVE_NAME=(미정)
BLARIYO_BUSINESS_REGISTRATION_NUMBER=(미정)
BLARIYO_MAIL_ORDER_REGISTRATION_NUMBER=(미정)
BLARIYO_OPERATOR_ADDRESS=(미정)
BLARIYO_OPERATOR_PHONE=(미정)
```

## 6. 확인 한계

- 자동 접근 기준 조사이므로 로그인, 동적 렌더링, bot 차단, 지역·브라우저 조건에 따라 실제 표시와 다를 수 있다.
- 뽐뿌와 피지알21은 자동 접근에서 상세 정책·푸터 확인이 제한됐다.
- 사업자 여부, 전자상거래 해당 여부, 주소·전화번호 공개 범위는 법무 판단이 필요하다.
- 이 문서는 벤치마크 참고 자료이며, 법적 결론이나 출시 승인 근거가 아니다.
