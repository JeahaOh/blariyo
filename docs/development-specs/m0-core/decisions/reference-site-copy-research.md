# 커뮤니티 사이트 카피·타이틀 조사

- 문서 상태: OD-M0-013 카피 결정을 위한 참고 조사
- 대상 결정: [OD-M0-013](./open-decisions.md)
- 관련 문서: [M0 Core 카피안](./copy-proposals.md)
- 확인일: 2026-09-03

## 1. 목적

국내 커뮤니티·유머 사이트의 홈 title, meta description, OG 문구, 슬로건성 문구를 확인해
블라리요 카피 방향을 정한다.

이 문서는 벤치마크 참고 자료다. 각 사이트의 현재 문구는 운영자가 언제든 바꿀 수 있으므로,
확정 카피 정본으로 사용하지 않는다.

## 2. 조사 요약

대부분의 참고 사이트는 강한 광고 문구보다 아래 구조를 사용한다.

- 서비스명 단독 또는 서비스명 + 짧은 분류어
- `유머`, `이슈`, `커뮤니티`, `게시판`, `정보` 같은 직접어
- 긴 슬로건보다 title·description·게시판명이 중심
- 브랜드 문구가 있더라도 짧게 사용

따라서 블라리요도 홈 메인은 `블라리요`와 `블라블라블라`를 중심에 두고, 검색·공유 metadata에는
`블라블라` 톤을 유지하면서 `웃긴 글과 짤`을 최소 설명으로 넣는다.

## 4. 블라리요 적용 판단

참고 사이트 기준으로 블라리요에는 아래 조합이 가장 맞다.

| 적용 위치 | 카피 |
| --- | --- |
| 메인 슬로건 | 블라리요 |
| 홈 보조 문구 | 블라블라블라 |
| 홈 `<title>` | 블라리요 - 블라블라블라 |
| 홈 `description` | 블라리요에서 블라블라블라 |
| 홈 `og:title` | 블라리요 |
| 홈 `og:description` | 블라리요에서 블라블라블라 |
| 푸터 브랜드 한 줄 | 블라블라블라 |

이 조합은 화면과 metadata 모두 `블라리요/블라블라` 톤을 유지한다. 서비스 성격 설명은 title의
`블라리요`와 실제 게시판·글 목록에서 보완한다.

## 5. 피해야 할 방향

- `출퇴근길`, `한 정거장` 같은 사용 맥락을 대표 카피에 강하게 넣지 않는다.
- `짧게 보고 웃고 가는`처럼 캠페인 문구에 가까운 표현은 줄인다.
- `오늘의 웃긴 글`처럼 특정 기존 서비스와 너무 가까워 보이는 구조를 피한다.
- `No.1`, `국내 최대`, `트렌드의 중심`처럼 검증되지 않은 과장 표현을 쓰지 않는다.
- `블라리요입니다`를 화면 메인과 metadata에 반복하지 않는다.

## 6. 확인 한계

- 일부 사이트는 접근 환경에 따라 bot 차단, redirect, 구형 encoding 이슈가 있었다.
- 뽐뿌는 직접 HTTPS 요청이 403이어서 검색 노출 결과와 접근 가능한 URL을 참고했다.
- 율도는 공식 도메인 첫 HTML에서 `YULDO` title만 확인했고, 별도 meta description은 확인되지 않았다.
- 피지알21은 공식 도메인과 주요 게시판 경로가 자동 접근에서 `연결 확인 중` 화면으로 응답해 실제 홈 title/meta를 확인하지 못했다.
- 각 사이트의 문구는 확인일 기준이며, 이후 변경될 수 있다.
