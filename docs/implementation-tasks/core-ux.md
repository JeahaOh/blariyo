# Core 화면 마감 task

현재 정적 대조로 발견한 P0 화면 수용 잔여다. 각 task는 해당 명세의 완료 조건을 먼저 확인하고 실제 브라우저에서 회귀를 검증한다. 분석 문서만으로 장애를 재현했다고 간주하지 않는다.

## UX-01 정책 이력 변경 후 본문 위치

- **목표:** 긴 정책 본문에서 버전을 바꿀 때 본문 상단 및 키보드 초점 이동을 일관되게 한다.
- **선행:** 정책·권리 명세와 현재 `PolicyViewer.vue` 구현 확인.
- **범위:** 버전 선택 후 스크롤/포커스 동작, 화면 읽기 순서, 좁은 화면 회귀.
- **완료 증거:** 버전 전환 자동/브라우저 검사, 키보드 초점 및 긴 본문 실제 화면 확인, 결과 기록.

## UX-02 공개 상세 소셜 메타데이터

- **목표:** SSR 상세 페이지가 OG/Twitter 이미지 대체텍스트와 이미지 크기를 제공한다.
- **선행:** 공개 게시글 상세 명세의 이미지 선택·대체텍스트 계약 확인.
- **범위:** 서버 렌더링 meta 태그 생성과 존재하지 않는/선택 이미지 상태.
- **완료 증거:** 대표 상세 HTML의 OG/Twitter 속성 검사, 이미지/alt/크기 경계 테스트.

## UX-03 목록 페이지 변경 후 초점

- **목표:** 페이지 이동 뒤 사용자가 새 결과의 제목을 바로 확인할 수 있게 한다.
- **선행:** 목록의 pagination 및 접근성 계약 확인.
- **범위:** 페이지 변경 시 제목 초점 또는 동등한 보조기기 안내, 키보드 탐색.
- **완료 증거:** 페이지 이동 브라우저 검사와 키보드/접근성 트리 확인.

## UX-04 하단 오류 재시도와 공유 피드백

- **목표:** 목록 하단 추가 조회 오류를 해당 영역에서 재시도하고, 브라우저 공유 결과를 안내한다.
- **선행:** 명세가 정한 하단 조회 오류 상태와 Web Share fallback 확인.
- **범위:** 재시도 중복 방지, 재시도 성공/실패, 공유 성공/취소/미지원 상태.
- **완료 증거:** 각 상태의 브라우저 테스트와 수동 화면 확인; 취소를 성공으로 표시하지 않음.

## UX-05 동의 저장·쿠키 삭제 실패 안내

- **목표:** 분석 동의 저장소 읽기 또는 cookie 삭제가 실패하면 사용자가 상태를 알 수 있다.
- **선행:** 분석 동의 명세와 GA4 OFF 경계 확인.
- **범위:** storage 접근 예외와 cookie 삭제 실패의 UI·재시도 경로. 실제 분석 tag 활성화는 범위 밖.
- **완료 증거:** 예외 주입 테스트, 실패 뒤 동의/추적 상태 비활성 확인, 오류 안내 화면 기록.

## UX-06 공개 탭 색상 기준 정렬

- **목표:** 퍼블리싱 검토물과 앱의 게시판 탭 색상 차이를 제품 색상 기준에 맞춘다.
- **선행:** `planning/07-color-palette.md`에서 적용 색 결정 및 승인.
- **범위:** 앱 스타일과 관련 화면/정적 검토물의 일치.
- **완료 증거:** 색상 토큰 참조와 대표 해상도 화면 비교. 결정 전 임의 색상 적용 금지.
