## 공통 정책 계약

- 게시판은 `유머`, `이야기` 2개만 운영한다. `/`는 두 게시판의 혼합 최신 목록이며 별도 게시판이나 세 번째 메뉴가 아니다.
- 공개 목록은 광고 행을 제외한 게시글 20개, 상세 하단은 같은 게시판의 현재 글 주변 게시글 20개를 사용한다.
- M0 게시글은 운영자가 출처와 권리를 확인해 직접 발행한다.
- 자동 수집은 M1 운영 자동화 후보이며 결과는 임시 후보 큐에만 저장한다. 운영자 검토와 수동 최종 발행 없이 공개할 수 없다.
- 필수 내부 운영 통계와 선택 GA4를 서로 다른 목적, 식별자, 저장소, 철회 절차로 운영한다.
- 상세 광고는 본문·출처 다음, 하단 목록 중간, 목록 아래만 허용한다.
- 광고 호출 실패는 광고 차단으로 간주하지 않는다. 확정 차단 때도 안내만 제공하고 콘텐츠 열람을 제한하지 않는다.
- 제휴 링크에는 링크와 가까운 위치에 제휴 관계와 수수료 수취 사실을 분명히 고지한다.

## 작성 기준

- 운영자 큐레이션형 M0와 M1 이후 확장 항목을 구분한다.
- 정책 문서는 조항형 본문과 핵심 표를 함께 제공한다.
- 기능·수탁자·국외이전이 바뀌면 배포 전에 네 문서를 함께 재검토한다.
