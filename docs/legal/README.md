## 작성 기준

- 운영자 큐레이션형 유머 피드 M0 기준으로 작성한다.
- 회원가입, 댓글, 제보, 광고 집행 전 상태와 이후 확장 항목을 구분한다.
- 사업자명, 대표자, 주소, 연락처, 개인정보 보호책임자는 확정 전까지 `[입력 필요]`로 둔다.
- 정책 문서는 화면에서 읽기 쉬운 조항형 본문과 핵심 요약을 함께 제공한다.
