# 블라리요 쿠키 설정 안내 초안

- 문서 상태: 초안
- 시행일: `[입력 필요]`
- 서비스명: `블라리요`

## 1. 쿠키 사용 목적

블라리요는 서비스 제공, 보안, 방문 분석, 광고 설정을 위해 쿠키 또는 유사 기술을 사용할 수 있다.

## 2. 쿠키 구분

| 구분 | 목적 | 필수 여부 |
| --- | --- | --- |
| 필수 쿠키 | 보안, 세션 유지, 쿠키 설정 저장, 광고 차단 안내 닫기 상태 저장 | 필수 |
| 분석 쿠키 | 방문 수, 게시글 선택, 상세 체류, 화면 흐름, 오류 분석 | 선택 |
| 광고 쿠키 | 광고 노출 빈도, 광고 품질, 광고 설정 저장 | 선택 |

## 3. 필수 쿠키

필수 쿠키는 서비스의 기본 동작을 위해 사용한다. 이용자가 별도로 끌 수 없으며, 브라우저 설정으로 차단할 경우 일부 기능이 정상 동작하지 않을 수 있다.

| 이름 후보 | 목적 | 보관 기간 |
| --- | --- | --- |
| `blariyo_cookie_consent` | 쿠키 선택 상태 저장 | 12개월 |
| `blariyo_adblock_dismissed` | 광고 차단 안내 닫기 상태 저장 | 세션 |
| `blariyo_session` | 보안과 세션 상태 | 세션 |

## 4. 분석 쿠키

분석 쿠키는 서비스 개선을 위한 통계 목적으로만 사용한다.

| 항목 | 설명 |
| --- | --- |
| 수집 이벤트 | 페이지 조회, 게시글 선택, 상세 체류, 공유 실행 |
| 도구 후보 | Google Analytics 4 |
| 보관 기준 | 원본 이벤트 90일 후 집계 데이터만 보관 |
| 선택 방법 | 쿠키 설정 화면에서 켜기/끄기 |

## 5. 광고 쿠키

광고 쿠키는 광고 노출 품질과 빈도 관리를 위해 사용할 수 있다. 광고 집행 전에는 비활성 상태로 둔다.

| 항목 | 설명 |
| --- | --- |
| 목적 | 광고 노출, 빈도 제한, 광고 성능 확인 |
| 도구 후보 | Google AdSense 또는 계약 광고 사업자 |
| 선택 방법 | 쿠키 설정 화면에서 켜기/끄기 |

## 6. 설정 변경

이용자는 푸터의 `쿠키 설정`에서 언제든지 선택을 변경할 수 있다.

선택지는 다음과 같다.

1. 필수만 사용
2. 분석 허용
3. 광고 허용
4. 모두 허용
5. 저장

## 7. 브라우저 설정

이용자는 브라우저 설정에서도 쿠키 저장을 제한하거나 삭제할 수 있다. 브라우저에서 쿠키를 모두 차단하면 설정 저장, 세션 유지, 일부 광고·분석 기능이 제한될 수 있다.

## 8. 변경 고지

쿠키 사용 목적, 보관 기간, 사용 도구가 변경되면 이 문서를 갱신하고 시행일을 표시한다.
