# 블라리요 쿠키 설정 안내 초안

- 문서 상태: 출시 전 확정 필요
- 시행일: `[출시 차단: 시행일 입력 필요]`
- 서비스명: `블라리요`

## 1. 분리 원칙

- 필수 내부 운영 통계는 자체 `anonymous_id`, `session_id`만 사용하며 제3자에게 보내지 않는다.
- 선택 GA4와 선택 광고는 각각 동의한 뒤에만 관련 태그와 저장소를 사용한다.
- 분석 또는 광고를 거부해도 게시글과 같은 게시판의 주변 목록을 열람할 수 있다.

## 2. 쿠키·로컬·세션 저장소

| 저장소 | 이름 후보 | 구분 | 목적 | 생성 조건 | 만료·삭제 |
| --- | --- | --- | --- | --- | --- |
| Cookie | `[출시 차단: 실제 인증 쿠키명 확정 필요]` | 필수 | 관리자·M1 인증 세션 | 로그인 성공 시 | 로그아웃 또는 서버 설정 만료 |
| Cookie | `_ga`, `_ga_*` | 선택 분석 | GA4 이용자·세션 구분 | 분석 동의 후 | 동의 철회 시 삭제, `[출시 차단: 실제 만료 확정 필요]` |
| Cookie | `[출시 차단: 광고 쿠키명 확정 필요]` | 선택 광고 | 광고 노출·측정 | 광고 동의 후 | 동의 철회 시 삭제, 사업자 설정 기간 |
| `localStorage` | `blariyo_consent` | 필수 | 분석·광고 선택과 선택 시각 저장 | 선택 저장 시 | 마지막 선택 후 12개월 또는 설정 초기화 시 |
| `localStorage` | `blariyo_anonymous_id` | 필수 운영 통계 | 7일 이내 재방문 구분 | 공개 화면 첫 진입 시 | 발급 후 7일 고정, 초기화 시 즉시 삭제 |
| `localStorage` | `blariyo_ad_frequency` | 선택 광고 | 광고 노출 빈도 관리 | 광고 동의 후 | 해당 현지 날짜 종료 또는 광고 동의 철회 시 |

| `sessionStorage` | `blariyo_adblock_notice_dismissed` | 필수 UI | 확정 차단 안내 반복 방지 | 안내 닫기 시 | 탭 종료 시 |

실제 이름과 기간이 표와 다르면 이 문서를 먼저 갱신한다. 출시 차단값이 남은 도구는 production에서 로드하지 않는다.

## 3. 식별자 생성·만료

- `anonymous_id`와 `session_id`는 Web Crypto 기반 128비트 이상 무작위 UUID로 생성한다.
- 서버에는 브라우저 원문 대신 HMAC 값만 저장하고 회원 정보, IP 원문, GA 식별자와 결합하지 않는다.
- `anonymous_id`의 7일 만료는 활동으로 연장하지 않는다.
- `session_id`는 마지막 활동 후 30분이 지나면 같은 탭에서도 새로 발급한다.

## 4. 선택과 철회

설정 화면은 `필수만 사용`, `분석 허용`, `광고 허용`, `모두 허용`, `선택 저장`을 제공한다.

- 분석 철회: GA 태그 전송을 즉시 중단하고 `_ga*` 쿠키와 관련 선택 분석 값을 삭제한다.
- 광고 철회: 광고 태그 전송을 중단하고 광고 쿠키와 `blariyo_ad_frequency`를 삭제한다.
- 내부 통계 초기화: 현재 내부 식별자의 서버 원시 이벤트 삭제를 요청하고 `anonymous_id`, `session_id`를 삭제한다. 계속 이용하면 연결되지 않는 새 식별자가 생성된다.

## 5. 광고 실패와 확정 차단

timeout, no-fill, 네트워크·스크립트 오류는 광고 실패다. 광고 사업자의 명시적 차단 응답 또는 두 가지 독립 신호가 함께 확인된 경우만 확정 차단으로 처리한다. 판정이 모호하면 실패로 처리하며 차단 안내를 띄우지 않는다. 어느 경우에도 콘텐츠 열람을 막지 않는다.

## 6. 브라우저 설정과 변경 고지

브라우저에서 저장소를 삭제하거나 차단할 수 있다. 이 경우 설정과 세션 구분이 초기화될 수 있지만 공개 콘텐츠 열람은 유지한다. 저장 목적, 이름, 기간, 도구가 바뀌면 이 문서와 개인정보처리방침을 함께 갱신한다.
