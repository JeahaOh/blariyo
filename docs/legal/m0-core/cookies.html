쿠키와 브라우저 저장소 안내

시행일: 2026년 9월 20일

공개 게시글 열람

블라리요는 게시글 조회 수 계산을 위해 방문자 식별용 쿠키, 로컬 저장소 또는 세션 저장소를 만들지 않습니다. Google Analytics와 광고 기능은 비활성이므로 관련 태그·쿠키와 선택 동의 배너를 표시하지 않습니다.

관리자 인증과 서비스 보호

관리자 페이지에서는 Cloudflare Access 인증을 사용합니다. 일반 방문자용 회원가입과는 별개이며 관리자 인증 유지와 서비스 보호에 필요한 저장소를 확인해 안내합니다.

관리자 로그인 시 CF_Authorization 쿠키가 blariyo.com과 조직의 cloudflareaccess.com 도메인에 사용됩니다. 인증 세션은 6시간이며 로그인 과정에서 임시 상태·보안 확인 쿠키가 추가될 수 있습니다. 일반 열람용 방문자 식별 쿠키와 구분합니다.

확인·삭제 방법

사용하는 브라우저의 개인정보 또는 사이트 데이터 설정에서 쿠키와 저장소를 확인·삭제·차단할 수 있습니다. 관리자 인증에 필요한 저장소를 차단하면 로그인이 제한될 수 있습니다.
