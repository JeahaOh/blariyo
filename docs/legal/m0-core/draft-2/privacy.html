1. 어떤 정보를 왜 처리하나요?

블라리요는 로그인 없이 짤을 보는 서비스입니다. 일반 회원가입, 이용자 글쓰기, 분석·광고 기능은 현재 제공하지 않습니다.

목적 처리 정보 보유 기준
화면·이미지 제공과 오류 대응 요청 시 전달되는 IP·브라우저 정보, 요청 일시·경로·응답 상태. 일반 앱·웹 로그에는 요청 식별값·축약 경로·오류 코드 등 필요한 정보만 기록 일반 로그 최대 7일
보안·관리자 접근 제어 필요한 접근 보안 기록, 운영자 인증 식별·권한 정보와 인증 결과 접근 보안 기록 90일. 운영자 매핑의 유지·종료 기준은 확정 필요
관리자 발행·숨김 이력 작업자, 대상, 변경 결과·시각 운영 기간 유지 기준의 적정성·종료 후 삭제 시점 확정 필요
일반 문의 회신 이메일, 문의 내용, 제출한 첨부 자료 회신 등 처리 목적 달성 후 지체 없이 파기
권리 요청 확인·처리 회신 이메일, 대상 URL, 요청 내용, 제출한 이름·단체명과 권리 소명 자료 요청 처리·필요한 법정 절차가 끝나고 보존 필요가 없어지면 지체 없이 파기

접속 정보는 요청 과정에서, 문의 자료는 이용자가 보낸 이메일로 받습니다. 필요한 정보가 없으면 문의 확인·회신이 제한될 수 있습니다. 주민등록번호나 소명에 불필요한 민감정보는 보내지 마세요. 불필요한 정보는 확인 후 삭제하거나 가립니다.

조회 수 계산을 위해 방문자 식별값이나 개인별 조회 이력을 저장하지 않으며, 보안 기록과 결합해 방문 이력을 만들지 않습니다. 개인정보를 생성형 AI 학습용으로 제공하지 않습니다.

진행 중인 분쟁 또는 법령상 보존 의무가 있는 자료는 필요한 범위만 분리 보관하며 종료 조건을 기록합니다. 개인정보처리시스템의 개인정보 접근 기록은 해당 법령에 따라 최소 1년, 2년 보존 대상이면 최소 2년을 보관합니다. 일반 방문·오류 로그와는 구분합니다.

3. 파기와 보호

기간이 끝나거나 처리 목적이 달성되면 전자 자료는 복구하기 어렵게 삭제하고 종이 자료는 분쇄·소각합니다. 법령상 보존이 필요하면 근거·항목·기간을 알리고 분리 보관합니다. 백업도 정해진 순환 주기에 따라 삭제합니다. 메일은 수신·발신·첨부·휴지통 사본까지 삭제하며, 제공 사업자 내부 백업의 삭제 완료 시점은 사업자의 삭제 정책에 따릅니다.

접근 권한 제한, 전송 암호화, 비밀정보 분리와 보관 기간 점검을 운영 기준으로 삼습니다. [출시 차단: 실제 안전조치, 사고 대응, 백업 보유·삭제 및 복원 후 재삭제 절차 확인]

4. 쿠키와 자동 수집
