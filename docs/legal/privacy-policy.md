# 블라리요 개인정보처리방침 초안

- 문서 상태: 출시 전 확정 필요
- 정합성 검토일: 2026-08-19
- 버전: `v0.1`
- 시행일: `[출시 차단: 시행일 입력 필요]`
- 서비스명: `블라리요`
- 개인정보처리자: `[출시 차단: 운영자명·사업자 정보 입력 필요]`
- 개인정보 보호책임자: `[출시 차단: 성명·직책 입력 필요]`
- 개인정보 문의: `[출시 차단: 이메일·전화번호·주소 입력 필요]`

위 공통 출시 차단값과 M0에서 실제 사용하는 수탁자가 확정되기 전에는 M0를 production에
공개하지 않는다. 소셜 로그인, GA4와 광고의 미확정 값은 M0 공개 전체가 아니라 해당 후속 기능의
활성화를 차단한다.

이 초안은 M0와 후속 기능의 처리 항목을 함께 설계한다. 실제 공개본에는 배포 시점에 활성화된
기능만 현재형으로 남긴다. 회원·소셜 로그인은 M1, 자동 수집·GA4·광고는 각 기능을 활성화하기
전까지 수집·처리하지 않는다.

개인정보처리자는 개인정보 보호법 제30조에 따라 정보주체의 개인정보를 보호하고 관련 고충을 처리하기 위해 다음과 같이 개인정보처리방침을 수립·공개한다.

## 핵심 요약

| 처리 목적 | 소셜 가입·로그인·계정 관리, 공개 콘텐츠 제공, 보안·오류 대응, 최소 운영 통계, 선택 GA4, 권리자 요청 처리 |
| 제3자 제공 | 원칙적으로 없음. 법령 또는 별도 동의가 있는 경우만 제공 |
| 처리위탁 | 호스팅·이미지 저장·이메일 사업자 확정 후 수탁자와 업무 공개 |
| 정보주체 권리 | 열람·정정·삭제·처리정지·동의 철회·해당 시 전송 요구 |

이 요약은 이해를 돕기 위한 것으로 아래 전문과 내용이 다르면 전문을 우선한다.

## 제1조 개인정보의 처리 목적과 법적 근거

| 처리 업무 | 목적 | 법적 근거·조건 |
| --- | --- | --- |
| 공개 서비스 요청 | `/meme` 목록, 게시글 상세, 공유·정책 화면 제공 | 개인정보 보호법 제15조 제1항 제4호 또는 제6호 적용 여부를 출시 전 확정 |
| 소셜 회원가입·로그인 | 본인 계정 식별, 가입 의사 확인, 로그인 세션 발급, 중복·부정 이용 방지 | 이용약관 이행과 회원가입 단계의 개인정보 수집·이용 동의 |
| 회원 계정 관리 | 소셜 계정 연결 상태, 약관 동의 이력, 탈퇴와 문의 처리 | 계약 이행 및 법령상 필요한 동의·보존 근거 |
| 보안·오류 대응 | 비정상 요청 차단, 장애 분석, 서비스 안정성 확보 | 개인정보 보호법 제15조 제1항 제6호의 정당한 이익 적용 여부와 이익형량을 출시 전 문서화 |
| 필수 내부 운영 통계 | 화면별 이용량, 세션당 소비, 7일 이내 재방문과 장애 판단 | 최소 식별자만 사용하며 제15조 제1항 제6호 적용 여부와 이익형량을 출시 전 문서화 |
| 선택 분석 | 유입 채널, 기기, 화면 흐름, 캠페인 성과 분석 | 분석 쿠키에 대한 별도 동의 후 처리 |
| 선택 광고 | 광고 노출 빈도, 성과와 품질 측정 | 광고 쿠키에 대한 별도 동의 후 처리 |
| 쿠키 선택 관리 | 분석·광고 동의 여부와 선택 시각 저장 | 선택 이행과 증명에 필요한 범위 |
| 권리자 요청 | 게시 중단·출처 정정·개인정보 삭제 요청 확인과 회신 | 요청자가 보낸 이메일 처리의 적법 근거와 고지 방식을 출시 전 확정 |
| 자동 수집 후보 검수 | 공개 출처의 게시 후보를 임시 큐에서 중복·품질 검수 | 공개 정보의 수집 범위와 적법 근거를 출처별로 검토하고 자동 공개하지 않음 |

처리 목적을 변경하는 경우 법령상 허용 여부를 확인하고 필요한 경우 별도 동의를 받는다.

## 제2조 처리하는 개인정보의 항목과 수집 방법

`짤/meme` 게시판은 로그인하지 않아도 열람할 수 있다. M1부터 네이버·카카오·Google·Apple
계정으로 회원가입과 로그인을 제공한다. 소셜 제공자의 동의 화면과 별도로 블라리요 이용약관
동의 및 회원가입 개인정보 수집·이용 동의를 받아야 가입이 완료된다. 가입 화면에서 이
개인정보처리방침 전문을 확인할 수 있게 한다. 소셜 계정 비밀번호는 블라리요가 전달받거나
저장하지 않는다.

| 구분 | 항목 | 필수·선택 | 수집 방법 |
| --- | --- | --- | --- |
| 접속·보안 | IP 주소, User-Agent, 접속 일시, 요청 URL, referer, 응답 상태, 오류 로그 | 필수 처리 | 서비스 요청 시 자동 생성 |
| 회원 계정 | 블라리요 회원 번호, 계정 상태, 가입·최근 로그인·탈퇴 시각, 이용약관·개인정보처리방침 동의 버전과 시각 | 가입 필수 | 가입 완료·로그인·동의 시 생성 |
| 소셜 연동 공통 | 제공자 코드, 제공자별 고유 식별자, 연동·최근 인증 시각 | 가입 필수 | 이용자가 선택한 소셜 제공자로부터 수신 |
| 소셜 프로필 | 이메일, 이메일 확인 여부, 이름 또는 닉네임, 프로필 이미지 URL 중 제공자가 제공하고 이용자가 동의한 항목 | 선택 또는 제공자별 필수 | 소셜 제공자 동의 후 수신 |
| 로그인 보안 | OAuth `state`·`nonce`·PKCE 검증값, 인증 성공·실패 기록, 세션 식별자 | 필수 처리 | 인증 요청·callback·세션 발급 시 생성 |
| 내부 운영 통계 | 무작위 `anonymous_id`, 무작위 `session_id`, 게시판 코드, 게시글 번호, 화면 조회·선택·스크롤·공유 이벤트, 발생 시각 | 필수 처리 | 공개 화면 이용 시 자동 생성 |
| 쿠키 선택 | 분석·광고 동의 여부, 정책 버전, 선택 시각 | 후속 선택 기능 활성화 시 필수 저장 | 활성 기능의 쿠키 배너·설정 modal에서 저장 |
| 선택 분석 | GA client ID, 페이지·스크롤·공유 이벤트, 제한된 기기·유입 정보 | 선택 | 분석 동의 후 분석 사업자 태그로 수집 |
| 선택 광고 | 광고 식별자·쿠키, 광고 노출·클릭·빈도·성과 정보 | 선택 | 광고 동의와 광고 실험 시작 후 수집 |
| 권리자 요청 | 대상 URL, 요청 유형, 이메일, 요청 내용, 이름·단체명과 권리·대리 소명 자료(제출하는 경우) | 요청 처리 필수 | 요청자가 푸터의 확정된 이메일 채널로 제출 |
| 일반 문의 | 이메일, 문의 내용, 첨부 자료 | 문의 시 필수 | 문의자가 확정된 접수 채널로 제출 |
| 후보 큐 | 출처 URL·도메인, 공개 제목, 이미지 후보 URL metadata, 수집 시각 | 후속 운영 검수 | 자동 수집 기능 활성화 후 worker가 임시 저장 |

### 소셜 제공자별 수신 항목

| 제공자 | 가입 식별에 사용하는 항목 | 추가로 요청할 수 있는 최소 항목 | 운영 기준 |
| --- | --- | --- | --- |
| 네이버 | 애플리케이션별 고유 회원 식별자 `id` | 이메일, 별명, 프로필 이미지 | 성별, 생일, 연령대, 출생연도, 휴대전화번호는 요청하지 않음 |
| 카카오 | 서비스별 회원번호 | 카카오계정 이메일, 닉네임, 프로필 이미지 | 회원번호를 기본 키로 사용하고 이메일을 고유 키로 사용하지 않음 |
| Google | OpenID Connect `sub` | `email`, `email_verified`, `name`, `picture` | `openid email profile` 범위만 요청 |
| Apple | Sign in with Apple `sub` | 이메일, 이름 | 이름은 최초 승인 때만 전달될 수 있으며 사용자가 이메일 가리기를 선택하면 중계 주소를 저장 |

- 제공자가 선택 항목을 주지 않거나 이용자가 동의하지 않으면 해당 항목 없이 가입 가능한 구조를 우선한다. 서비스에 꼭 필요한 항목이 생기면 가입 화면에서 이유를 별도로 설명하고 동의를 받는다.
- 소셜 제공자 식별자, 이메일, 닉네임, 프로필 이미지는 GA4 이벤트·GA4 User-ID·광고 식별값으로 전송하지 않는다.
- 로그인 전용 access token과 refresh token은 사용자 정보 확인과 세션 발급에 필요한 최소 시간만 메모리 또는 단기 저장소에서 사용한 뒤 폐기한다. 제공자 API의 지속 호출이 필요한 기능을 추가해 장기 보관할 때는 암호화, 보유 기간과 철회 절차를 이 방침에 먼저 공개한다.

- 주민등록번호, 여권번호, 운전면허번호, 외국인등록번호 같은 고유식별정보는 수집하지 않는다.
- 사상·신념, 건강, 성생활, 유전·범죄경력 같은 민감정보는 의도적으로 수집하지 않는다.
- 권리자 요청자가 소명에 불필요한 민감정보나 고유식별정보를 제출하지 않도록 안내하고 확인 즉시 마스킹 또는 삭제한다.

## 제3조 내부 식별자와 최소 수집 기준

| 항목 | 생성·저장 | 만료 | 초기화·철회 |
| --- | --- | --- | --- |
| `anonymous_id` | Web Crypto 기반 128비트 이상 무작위 UUID를 `localStorage`에 저장하고 서버에는 HMAC 값만 저장 | 발급 후 7일 고정, 활동으로 연장하지 않음 | 초기화 요청 시 서버 원시 이벤트 삭제 요청 후 브라우저 값 삭제 |
| `session_id` | 무작위 UUID를 `sessionStorage`에 저장하고 서버에는 HMAC 값만 저장 | 30분 무활동, 탭 종료 또는 저장값 소실 시 종료 | 초기화 시 즉시 삭제 |

1. 내부 식별자는 이메일, 블라리요 회원 번호, 소셜 제공자 식별자, IP 원문, GA client ID와 결합하지 않는다.
2. 원시 이벤트에는 제목, 본문, 댓글, 권리자 요청 내용이나 공유 대상 URL 전체를 넣지 않는다.
3. 초기화 뒤 서비스를 계속 이용하면 연결되지 않는 새 식별자가 생성될 수 있다.
4. 분석 동의 철회와 내부 통계 식별자 초기화는 서로 다른 동작으로 제공한다.

## 제4조 개인정보의 처리 및 보유 기간

| 처리 항목 | 보유 기간 | 종료 후 처리 |
| --- | --- | --- |
| 접속·보안 로그 | 생성 후 90일 | 복구하기 어렵게 삭제 |
| 회원 계정과 소셜 연동 식별자 | 회원 탈퇴 시까지 | 탈퇴 시 계정·연동 정보 삭제, 법령상 보존 정보는 분리 보관 |
| 약관·개인정보처리방침 동의 이력 | 회원 탈퇴 시까지. 분쟁 대응에 필요한 경우 `[출시 차단: 보존 근거와 기간 확정 필요]` | 목적 종료 후 삭제 |
| OAuth 검증값 `state`·`nonce`·PKCE | 인증 요청 후 10분 이내 또는 callback 완료 시점 중 먼저 도래한 때 | 즉시 삭제 |
| OAuth access·refresh token | 로그인 callback 처리 완료 시까지. 장기 보관 기능은 현재 없음 | 사용자 정보 확인·세션 발급 후 즉시 폐기 |
| 로그인 성공·실패 기록 | 생성 후 90일 | 복구하기 어렵게 삭제 |
| 필수 내부 원시 이벤트 | 생성 후 90일 | 원시 이벤트 삭제, 개인을 식별하기 어려운 일별 집계만 보관 |
| 브라우저 `anonymous_id` | 발급 후 7일 | 자동 만료 또는 초기화 시 삭제 |
| 브라우저 `session_id` | 30분 무활동 또는 탭 종료까지 | 세션 종료 시 삭제 |
| 쿠키 선택 기록 | 마지막 선택일로부터 12개월 | 만료 후 다시 선택 요청 |
| 선택 분석 정보 | `[출시 차단: GA4 속성 보관 설정과 실제 기간 확정 필요]` | 동의 철회 시 전송 중단·삭제 가능한 브라우저 값 삭제 |
| 선택 광고 정보 | `[출시 차단: 광고 사업자 보유 기간 확정 필요]` | 동의 철회 시 전송 중단·삭제 가능한 브라우저 값 삭제 |
| 미발행 후보 | 수집 후 30일 또는 반려 시점 중 먼저 도래한 때 | metadata와 임시 파일 삭제 |

| 일반 문의 기록 | 처리 완료 후 1년 | 삭제 |

법령상 별도 보존 의무가 있으면 근거, 항목과 기간을 공개하고 다른 정보와 분리 보관한다.

## 제5조 개인정보의 제3자 제공

개인정보를 제3자에게 상시 제공하지 않는다. 정보주체의 별도 동의 또는 법률의 특별한 규정 등 개인정보 보호법 제17조·제18조에 해당하는 경우에만 제공하며, 제공이 시작되면 제공받는 자, 목적, 항목과 보유 기간을 이 방침에 공개한다.

소셜 로그인 과정에서는 이용자가 선택한 제공자에게 인증 요청을 보내고, 제공자가 이용자 동의에 따라 블라리요에 회원 식별자와 선택 프로필을 전달한다. 블라리요는 인증 protocol 수행에 필요한 callback URL, client ID, `state`·`nonce`와 authorization code/token 교환 요청만 전송하며, 블라리요 서비스 이용 내역이나 다른 소셜 계정 정보를 제공하지 않는다.

## 제8조 개인정보의 파기 절차 및 방법

1. 보유 기간 경과, 처리 목적 달성, 동의 철회 등 파기 사유가 발생하면 지체 없이 파기한다.
2. 운영 담당자가 파기 대상을 확인하고 개인정보 보호책임자의 기준에 따라 파기 결과를 기록한다.
3. 전자 파일과 데이터베이스 값은 복구·재생하기 어렵도록 삭제하고 백업본은 백업 순환 주기에 따라 삭제한다.
4. 종이 또는 출력물이 생긴 경우 분쇄하거나 소각한다.
5. 법령상 보존 의무가 있는 정보는 별도 논리 영역으로 분리하고 정해진 목적 외에 이용하지 않는다.

## 제9조 정보주체와 법정대리인의 권리 및 행사 방법

1. 정보주체는 개인정보 열람, 정정·삭제, 처리정지, 동의 철회와 법령상 적용되는 경우 개인정보 전송을 요구할 수 있다.
2. 권리 행사는 `[출시 차단: 권리 행사 이메일·우편 주소·전화번호 입력 필요]`로 본인 또는 적법한 대리인이 요청할 수 있다.
3. 요청자는 대상 정보와 요청 내용을 확인할 수 있는 최소 정보를 제출하며, 대리인은 위임 관계를 확인할 수 있는 자료를 제출한다.
4. 개인정보처리자는 본인·대리인 여부를 확인한 뒤 법정 기한 안에 처리 결과 또는 제한·거절 사유와 이의제기 방법을 알린다.
5. 법령에서 열람·삭제·처리정지를 제한하는 경우 그 근거를 안내한다.
6. 쿠키 설정에서는 분석·광고 동의를 즉시 철회할 수 있고, 내부 통계 식별자 초기화는 별도 기능으로 제공한다.
7. 회원은 계정 설정에서 탈퇴하거나 확정된 개인정보 문의 채널로 탈퇴를 요청할 수 있다. 탈퇴 시 블라리요 계정과 소셜 연동 정보를 삭제하고 제공자가 지원하는 범위에서 연동 해제·토큰 폐기를 요청한다.
8. 소셜 제공자에서 블라리요 연동만 해제한 경우 서비스 세션을 종료하고 재로그인 또는 계정 복구 방법을 안내한다.
9. `[출시 차단: 14세 미만 회원가입 허용 여부와 연령 확인 방식 확정 필요]` 법정대리인 동의 절차를 마련하기 전에는 14세 미만 가입을 허용하지 않는다.

### 전송요구권

블라리요 초기 서비스는 정보주체가 제공한 대규모 구조화 개인정보를 보유하지 않는다. 법령상 전송요구권 적용 대상과 전송 가능한 정보가 생기면 전송 범위, JSON·CSV 등 형식, 수신자 지정 방법, 진행 현황과 이력 확인 방법을 이 방침과 서비스 화면에 추가한다.

## 제10조 자동 수집 장치와 행태정보

1. 필수 저장소는 보안, 세션 구분, 쿠키 선택과 광고 차단 안내 반복 방지에 사용한다.
2. 소셜 로그인 과정의 세션 쿠키, OAuth `state`·`nonce`·PKCE 검증값은 로그인 위조와 재전송 공격 방지를 위한 필수 저장소이며 분석·광고 선택과 관계없이 사용한다.
3. GA4의 `_ga`, `_ga_*` 쿠키와 관련 Google tag는 저장된 분석 동의가 없는 최초 접속에서 생성·호출하지 않는다.
4. 광고 쿠키는 광고 동의를 받은 뒤에만 활성화한다.
5. 이용자는 최초 접속 하단 배너에서 `필수만 사용`, `설정`, `모두 허용`을 선택할 수 있다.
6. 선택 저장 뒤 modal과 배너를 닫고, 푸터의 쿠키 설정에서 언제든 변경하거나 철회할 수 있다.
7. 실제 저장소 이름, 목적, 생성 조건과 만료는 [쿠키 설정 안내](./cookie-settings.md)에 공개한다.

### 브라우저에서 거부·삭제하는 방법

- Chrome: 설정 → 개인정보 및 보안 → 서드 파티 쿠키 또는 인터넷 사용 기록 삭제
- Safari: 설정 → 개인정보 보호 → 웹사이트 데이터 관리
- Edge: 설정 → 쿠키 및 사이트 권한 → 쿠키 및 사이트 데이터 관리
- Firefox: 설정 → 개인정보 및 보안 → 쿠키와 사이트 데이터
- 시크릿·개인정보 보호 창을 사용하거나 브라우저 저장소를 직접 삭제할 수 있다.

모든 저장소를 차단하면 선택 기억과 세션 구분이 초기화될 수 있지만 공개 콘텐츠 열람은 유지한다.

### 맞춤형 광고와 행태정보

맞춤형 광고를 시작하기 전까지 광고 사업자에게 행태정보를 전송하지 않는다. 시작하려면 수집 주체, 목적, 항목, 보유 기간, 수집 방법, 거부 방법과 국외이전을 확정해 이 방침에 공개하고 광고 동의를 받아야 한다.

## 제11조 자동화된 결정과 AI 학습

블라리요는 소셜 로그인 성공 여부를 제공자의 인증 결과와 자체 보안 검증에 따라 처리하지만, 개인에게 법적 또는 중대한 영향을 주는 자동화된 결정을 하지 않는다. 이용자 개인정보를 생성형 AI 학습 데이터로 제공하지 않는다. 향후 해당 처리가 생기면 결정 기준·절차·방식, 결과 설명·거부·인적 재처리 요구 방법 또는 학습 데이터 출처·보호조치·삭제 요구 방법을 기능 공개 전에 이 방침에 추가한다.

## 제12조 개인정보의 안전성 확보 조치

1. 관리적 조치: 개인정보 처리 권한 최소화, 운영자 계정 분리, 처리 기록 점검, 권리 소명 자료 접근 제한과 정기적인 보유 정보 정리
2. 기술적 조치: 전송 구간 암호화, OAuth authorization code flow와 `state`·`nonce`·PKCE 검증, 세션 쿠키 `HttpOnly`·`Secure`·적절한 `SameSite`, 접근통제, 접속기록 보관·점검, 취약점·악성코드 대응, 내부 식별자 HMAC 처리와 provider client secret 분리
3. 물리적 조치: 서버·자료 보관 장소에 대한 제공 사업자의 물리적 접근통제 확인
4. 사고 대응: 유출·위조·변조·훼손 또는 그 가능성을 인지하면 영향 범위를 확인하고 법령상 통지·신고와 재발 방지 조치를 수행

## 제15조 개인정보처리방침의 변경과 개정 이력

1. 이 방침은 시행일부터 적용한다.
2. 변경 시 적용일과 주요 변경 내용을 원칙적으로 7일 전에 공지하고, 정보주체 권리에 중대한 영향을 주는 변경은 30일 전에 알린다.
3. 현재 적용 본문과 시행된 이전 버전의 전문을 `/privacy` modal 하단 개정 이력에서 확인할 수 있게 보관한다.
4. 개정 이력은 `버전, 적용 기간`만 표시하고 행 전체를 선택하면 해당 버전 전문을 연다. 현재 버전은 `yyyy.mm.dd ~ 시행 중`, 이전 버전은 `yyyy.mm.dd ~ yyyy.mm.dd` 형식을 사용한다.
5. 최초 버전은 `v0.1`이며 시행일은 `[출시 차단: 시행일 입력 필요]`이다.
