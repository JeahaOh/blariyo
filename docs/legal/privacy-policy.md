# 블라리요 개인정보처리방침 초안

- 문서 상태: 출시 전 확정 필요
- 시행일: `[출시 차단: 시행일 입력 필요]`
- 서비스명: `블라리요`
- 개인정보처리자: `[출시 차단: 운영자명·사업자 정보 입력 필요]`
- 개인정보 보호책임자: `[출시 차단: 보호책임자 입력 필요]`
- 문의: `[출시 차단: 문의 이메일 입력 필요]`

위 출시 차단값과 실제 수탁자·국외이전 항목이 확정되기 전에는 production 공개, GA4, 광고를 활성화하지 않는다.

## 1. 개인정보 처리 목적

| 구분 | 목적 | 적용 조건 |
| --- | --- | --- |
| 필수 서비스 처리 | 게시글 열람, 보안, 오류 대응 | 서비스 요청 시 |
| 필수 내부 운영 통계 | 피드·상세 이용량, 세션당 소비, 7일 이내 재방문, 장애 판단 | 제3자 전송 없이 항상 적용 |
| 선택 GA4 분석 | 유입 채널, 기기, 화면 흐름, 캠페인 분석 | 분석 동의 후에만 적용 |
| 선택 광고 | 광고 노출과 품질 측정 | 광고 실험 시작 및 광고 동의 후에만 적용 |
| 권리자·문의 처리 | 게시 중단·정정·재검토와 문의 회신 | 요청 접수 시 |
| 자동 수집 후보 검수 | 공개 출처의 후보를 임시 큐에서 검수 | 자동 수집 기능 활성화 시 |

필수 내부 운영 통계와 선택 GA4는 식별자, 저장소, 전송 대상과 철회 절차를 분리한다. 내부 식별자를 GA 식별자나 회원 정보와 결합하지 않는다.

## 2. 처리하는 항목

초기 `짤/meme` 게시판은 공개 이용자 회원가입을 제공하지 않는다.

| 구분 | 항목 | 수집 방법 |
| --- | --- | --- |
| 접속·보안 | IP 주소, User-Agent, 접속 일시, 요청 URL, referer, 오류 로그 | 요청 처리 시 자동 생성 |
| 필수 내부 통계 | 무작위 `anonymous_id`, 무작위 `session_id`, 피드·상세 조회, 게시판 코드, 게시글 번호, 발생 시각 | 공개 화면 이용 시 자동 생성 |
| 선택 GA4 | 페이지 조회, 게시글 선택, 체류·스크롤, 공유, 제한된 기기·유입 정보 | 분석 동의 후 수집 |
| 동의 설정 | 분석·광고 선택과 선택 시각 | 쿠키 설정에서 저장 |
| 권리자 요청 | 이름·단체명, 이메일, 대상 URL, 요청 내용, 권리·대리 소명 자료 | 요청자가 제출 |
| 일반 문의 | 이메일, 문의 내용, 첨부 자료 | 문의자가 제출 |
| 임시 후보 큐 | 출처 URL·도메인, 공개 제목, 이미지 후보 URL 메타데이터, 수집 시각 | 자동 수집 기능으로 생성 |

자동 수집 결과는 임시 후보 큐에만 저장한다. 운영자가 확인하고 이미지 저장과 발행을 실행한 항목만 공개하며 자동 발행하지 않는다.

## 3. 내부 식별자 계약

| 항목 | 생성·저장 | 만료 | 초기화·철회 |
| --- | --- | --- | --- |
| `anonymous_id` | Web Crypto 기반 128비트 이상 무작위 UUID, `localStorage` 저장, 서버에는 HMAC 값만 저장 | 발급 후 7일 고정, 활동으로 연장하지 않음 | `내부 통계 식별자 초기화` 시 서버 원시 이벤트 삭제 요청 후 브라우저 값 삭제 |
| `session_id` | 같은 방식의 무작위 UUID, `sessionStorage` 저장, 서버에는 HMAC 값만 저장 | 30분 무활동·탭 종료·저장값 소실 시 종료 | 초기화 시 즉시 삭제 |

- 두 식별자는 이메일, 회원 번호, IP 원문, GA client ID와 결합하지 않는다.
- 초기화 후 서비스를 계속 이용하면 필수 운영 통계를 위해 연결되지 않는 새 값이 생성된다.
- 분석 동의 철회는 GA4 전송 중단과 GA 쿠키 삭제를 뜻하며 내부 식별자 초기화와 별개다.

## 4. 보유 기간

| 항목 | 보유 기간 |
| --- | --- |
| 접속·보안 로그 | 90일 |
| 필수 내부 원시 이벤트 | 90일 후 삭제, 비식별 일별 집계만 보관 |
| 브라우저 `anonymous_id` | 발급 후 7일 |
| 브라우저 `session_id` | 30분 무활동 또는 탭 종료까지 |
| 동의 설정 | 마지막 선택일로부터 12개월 |
| 선택 GA4 정보 | `[출시 차단: GA4 속성·보관 설정과 실제 기간 확정 필요]` |
| 미발행 후보 | 수집 후 30일 또는 반려 시점 중 먼저 도래한 때 |
| 권리자 요청 기록 | 처리 완료 후 3년 |
| 일반 문의 기록 | 처리 완료 후 1년 |

법령상 별도 보관 의무가 있으면 해당 근거와 항목을 공개하고 분리 보관한다.

## 5. 제3자 제공과 처리 위탁

개인정보를 외부에 제공하지 않는다. 다만 이용자 동의 또는 적법한 법령상 요구가 있는 경우는 제외한다.

| 수탁자 | 업무 | 보유·이용 기간 |
| --- | --- | --- |
| `[출시 차단: 호스팅 사업자 입력 필요]` | 서버·데이터베이스 운영 | 계약 종료 시까지 |
| `[출시 차단: 이미지 저장 사업자 입력 필요]` | 게시글 이미지 저장·전송 | 계약 종료 또는 이미지 삭제 시까지 |
| `[출시 차단: 이메일 사업자 입력 필요]` | 문의·권리자 요청 회신 | 계약 종료 시까지 |
| `[출시 차단: GA4 계약 법인 입력 필요]` | 선택 방문 분석 | 동의 철회 또는 확정 보유 기간까지 |
| `[출시 차단: 광고 사업자 입력 필요]` | 선택 광고 노출·측정 | 동의 철회 또는 확정 보유 기간까지 |

수탁자 계약과 처리 항목이 확정되지 않은 기능은 활성화하지 않는다.

## 6. 국외이전

GA4 또는 광고 도구가 국외이전을 수반하면 `[출시 차단: 이전 국가, 법인, 항목, 목적, 시점·방법, 보유 기간, 거부 방법 입력 필요]`를 확정해 공개한 뒤 활성화한다. 확정 전에는 Google·광고 태그를 로드하지 않는다.

## 7. 파기와 정보주체 권리

보유 기간 종료 또는 목적 달성 시 전자 파일은 복구하기 어렵게 삭제하고, 법령상 보존 정보는 분리한다.

이용자는 열람, 정정, 삭제, 처리정지, 동의 철회를 `[출시 차단: 권리 행사 이메일 입력 필요]`로 요청할 수 있다. 쿠키 설정에서는 분석·광고 동의를 즉시 철회할 수 있으며, 내부 통계 식별자 초기화도 제공한다.

## 8. 쿠키와 브라우저 저장소

블라리요는 쿠키, `localStorage`, `sessionStorage`를 구분해 사용한다. 필수 내부 통계 식별자는 자체 브라우저 저장소에 두고, GA4 쿠키는 분석 동의 후에만 생성한다. 이름, 위치, 만료와 삭제 동작은 [쿠키 설정 안내](./cookie-settings.md)에 공개한다.

## 9. 안전성 확보 조치

관리자 최소 권한, 인증 정보의 안전한 저장, 접속 기록 점검, 불필요한 수집 제한, 권리 소명 자료 접근 제한, 식별자 HMAC 처리를 적용한다.
