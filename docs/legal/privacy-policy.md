# 블라리요 개인정보처리방침 초안

- 문서 상태: 초안
- 시행일: `[입력 필요]`
- 서비스명: `블라리요`
- 개인정보처리자: `[입력 필요]`
- 개인정보 보호책임자: `[입력 필요]`
- 문의: `[입력 필요]`

## 1. 개인정보 처리 목적

블라리요는 다음 목적을 위해 개인정보를 처리한다.

| 목적 | 내용 |
| --- | --- |
| 서비스 제공 | 게시글 열람, 페이지 이동, 공유 기능, 오류 대응 |
| 권리자 요청 처리 | 게시 중단, 정정, 소명 요청 접수와 처리 결과 회신 |
| 문의 처리 | 서비스 이용 문의, 정책 문의, 권리 침해 신고 답변 |
| 보안과 장애 대응 | 비정상 요청 탐지, 장애 분석, 서비스 안정성 확보 |
| 방문 분석 | 동의한 이용자의 방문 흐름, 게시글 소비 지표 분석 |
| 광고 설정 | 동의한 이용자의 광고 설정 저장과 광고 노출 품질 관리 |

## 2. 처리하는 개인정보 항목

M0 기준으로 회원가입을 제공하지 않는다. 기본 열람 과정에서 직접 회원 정보를 받지 않는다.

| 구분 | 항목 | 수집 방법 |
| --- | --- | --- |
| 접속 기록 | IP 주소, User-Agent, 접속 일시, 요청 URL, referer, 오류 로그 | 서비스 접속 시 자동 생성 |
| 분석 정보 | 페이지 조회, 스크롤, 체류, 게시글 선택, 공유 실행 이벤트 | 이용자 동의 후 수집 |
| 쿠키 설정 | 필수 쿠키, 분석 동의, 광고 동의, 광고 차단 안내 닫기 여부 | 이용자 선택 |
| 권리자 요청 | 이름 또는 단체명, 이메일, 요청 대상 URL, 권리 소명 자료, 요청 내용 | 권리자 요청 제출 |
| 문의 | 이메일, 문의 내용, 첨부 자료 | 문의 제출 |

## 3. 개인정보 보유 기간

| 항목 | 보유 기간 |
| --- | --- |
| 접속·보안 로그 | 90일 |
| 분석 이벤트 원본 | 90일 후 집계 데이터만 보관 |
| 쿠키 동의 기록 | 마지막 선택일로부터 12개월 |
| 권리자 요청 기록 | 처리 완료 후 3년 |
| 일반 문의 기록 | 처리 완료 후 1년 |

관계 법령에 따라 더 오래 보관해야 하는 경우 해당 법령에서 정한 기간 동안 보관한다.

## 4. 개인정보의 제3자 제공

블라리요는 이용자의 개인정보를 외부에 제공하지 않는다. 다만 다음 경우에는 예외로 한다.

1. 이용자가 사전에 동의한 경우
2. 법령에 따라 제출 의무가 있는 경우
3. 수사기관 또는 법원이 적법한 절차에 따라 요청한 경우

## 5. 개인정보 처리의 위탁

서비스 운영 과정에서 다음 업무를 외부 서비스에 맡길 수 있다.

| 수탁자 | 위탁 업무 | 보유·이용 기간 |
| --- | --- | --- |
| `[호스팅 사업자 입력]` | 서버와 데이터베이스 운영 | 위탁 계약 종료 시까지 |
| `[이메일 사업자 입력]` | 문의와 권리자 요청 회신 | 위탁 계약 종료 시까지 |
| Google Analytics | 방문 분석 | 이용자 동의 철회 또는 설정 기간까지 |
| `[광고 사업자 입력]` | 광고 노출과 광고 품질 측정 | 이용자 동의 철회 또는 설정 기간까지 |

확정 전 수탁자는 서비스 공개 전 실제 계약 기준으로 다시 정리한다.

## 6. 개인정보의 파기

1. 보유 기간이 끝나거나 처리 목적이 달성되면 지체 없이 파기한다.
2. 전자 파일은 복구하기 어렵게 삭제한다.
3. 종이 문서는 분쇄하거나 소각한다.
4. 법령상 보관 의무가 있는 정보는 다른 정보와 분리해 보관한다.

## 7. 정보주체의 권리와 행사 방법

이용자는 자신의 개인정보에 대해 열람, 정정, 삭제, 처리정지, 동의 철회를 요청할 수 있다.

요청은 `[입력 필요 이메일]`로 접수한다. 운영자는 본인 여부와 요청 내용을 확인한 뒤 처리 결과를 안내한다.

## 8. 자동 수집 장치의 설치·운영과 거부

블라리요는 필수 기능, 방문 분석, 광고 설정을 위해 쿠키 또는 유사 기술을 사용할 수 있다.

| 구분 | 목적 | 선택 |
| --- | --- | --- |
| 필수 쿠키 | 보안, 세션, 쿠키 설정 저장 | 항상 사용 |
| 분석 쿠키 | 방문 통계, 화면 흐름, 성능 개선 | 선택 |
| 광고 쿠키 | 광고 설정, 노출 빈도, 광고 품질 관리 | 선택 |

이용자는 `쿠키 설정` 화면에서 선택을 변경할 수 있다.

## 9. 개인정보의 안전성 확보 조치

운영자는 개인정보 보호를 위해 다음 조치를 적용한다.

1. 관리자 접근 권한 제한
2. 비밀번호와 인증 정보의 안전한 저장
3. 접속 로그 보관과 비정상 접근 점검
4. 운영자 계정의 최소 권한 원칙 적용
5. 불필요한 개인정보 수집 제한
6. 권리자 요청 자료의 접근 범위 제한
