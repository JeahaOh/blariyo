# 블라리요 권리자 요청 안내 초안

- 문서 상태: 초안
- 시행일: `[입력 필요]`
- 접수 이메일: `[입력 필요]`

## 1. 목적

블라리요는 운영자가 선별한 유머 게시글을 제공하면서 출처와 권리 상태를 확인한다. 게시글이 저작권, 초상권, 명예, 개인정보, 기타 권리를 침해한다고 판단하는 권리자는 이 안내에 따라 게시 중단, 정정, 출처 수정, 재검토를 요청할 수 있다.

## 2. 요청할 수 있는 사람

다음 사람 또는 단체가 요청할 수 있다.

1. 저작권자 또는 저작인접권자
2. 초상권, 개인정보, 명예 등 권리 침해를 주장하는 당사자
3. 권리자로부터 위임받은 대리인
4. 원 게시자 또는 원 출처 운영자

## 3. 요청 유형

| 유형 | 설명 |
| --- | --- |
| 게시 중단 | 게시글 또는 이미지의 비노출 요청 |
| 출처 정정 | 출처명, 원문 URL, 작성자 표시 수정 요청 |
| 내용 정정 | 본문 일부가 사실과 다르거나 오해를 유발하는 경우 |
| 개인정보 삭제 | 이름, 연락처, 얼굴, 계정명 등 개인정보 삭제 요청 |
| 재검토 | 이전 처리 결과에 대한 재검토 요청 |

## 4. 요청 시 필요한 정보

요청자는 아래 정보를 함께 보내야 한다.

1. 요청자 이름 또는 단체명
2. 연락 가능한 이메일
3. 요청 대상 게시글 URL
4. 요청 유형
5. 침해되었다고 보는 권리와 사유
6. 권리자임을 확인할 수 있는 자료 또는 대리 권한 자료
7. 원하는 조치

필요한 정보가 부족하면 운영자는 보완을 요청할 수 있다.

## 5. 처리 절차

```text
요청 접수
  -> 대상 게시글 확인
  -> 요청자와 권리 소명 확인
  -> 임시 비노출 또는 유지 판단
  -> 수정·삭제·비노출·반려 처리
  -> 처리 결과 회신
```

## 6. 임시 비노출 기준

다음 경우에는 검토가 끝나기 전이라도 임시 비노출할 수 있다.

1. 저작권 침해 가능성이 높고 소명 자료가 충분한 경우
2. 개인정보 또는 얼굴 등 식별 정보가 노출된 경우
3. 명예훼손, 모욕, 사생활 침해 위험이 큰 경우
4. 원 출처가 삭제되었거나 권리 상태를 확인하기 어려운 경우
5. 서비스 운영자가 즉시 조치가 필요하다고 판단한 경우

## 7. 처리 결과

운영자는 요청 내용에 따라 다음 중 하나로 처리한다.

| 결과 | 설명 |
| --- | --- |
| 삭제 | 게시글 또는 파일 제거 |
| 비노출 | 사용자 화면에서 숨김 |
| 정정 | 출처, 링크, 문구 수정 |
| 유지 | 권리 침해 소명이 부족하거나 정당한 이용으로 판단 |
| 보완 요청 | 자료가 부족해 추가 확인 요청 |

## 8. 허위 요청과 남용

정당한 권리 없이 게시 중단이나 정정을 반복적으로 요구하거나 허위 자료를 제출하면 요청 처리가 제한될 수 있다.

## 9. 보관

권리자 요청 기록은 분쟁 대응과 처리 이력 관리를 위해 처리 완료 후 3년간 보관한다.

## 10. 참고

저작권 침해에 따른 복제·전송 중단 요청은 저작권법 제103조와 저작권법 시행규칙 제13조의 절차를 참고한다.
