- 정합성 검토일: 2026-09-03
- 시행일: `2026년 9월 20일`
- 접수 이메일: `[출시 차단: 권리 침해 신고·요청 이메일 입력 필요]`

1차 접수 채널은 푸터의 이메일 링크다. 접수 이메일은 배포 환경 properties/config에서 주입하며,
실값이 확정되기 전에는 서비스를 production에 공개하지 않는다. 푸터에는 `mailto:`와 별도로 항상
접근 가능한 `이메일 주소 복사`를 제공한다. 복사 범위는 접수 이메일 주소뿐이며 제목·본문은 복사하지
않는다. browser에서 mail client 실행 성공·실패를 감지한다고 가정하지 않으며, 별도 form·API·접수
DB는 제공하지 않는다.

## 1. 요청 범위

저작권자, 초상권·개인정보·명예 등 권리 당사자, 적법한 대리인, 원 게시자·원 출처 운영자는 게시 중단, 출처·내용 정정, 개인정보 삭제, 처리 결과 재검토를 요청할 수 있다.

## 2. 필요한 정보

요청자 이름·단체명, 회신 이메일, 대상 URL, 요청 유형, 권리와 사유, 권리자·대리 권한 소명 자료, 원하는 조치를 제출한다. 필요한 범위를 넘는 주민등록번호 등은 제출하지 않는다.

푸터 이메일 링크 주변 또는 개인정보처리방침에는 다음 개인정보 처리 목적·항목·보유 기간과 거부 시 영향을 표시한다. 이메일 접수에 적용할 적법 근거와 고지 방식은 출시 전에 확정한다.

| 목적 | 항목 | 보유 기간 | 거부 시 영향 |
| --- | --- | --- | --- |
| 권리 관계 확인, 게시글 우선 숨김, 보완·결과 회신 | 이름·단체명, 이메일, 대상 URL, 요청 내용, 제출한 소명 자료 | 처리·법정 절차 종료 후 보존 필요가 없어지면 지체 없이 파기 | 필요한 정보를 보내지 않으면 요청 확인·회신이 제한될 수 있음 |

## 3. 처리 흐름

```text
이메일 수신
  -> 운영자 접수 확인
  -> 대상 게시글 우선 비노출
  -> 자료 완전성·대상 URL 확인
  -> 요청자와 게시 담당자·복제전송자에게 조치 통보
  -> 보완·소명 접수 및 재검토
  -> 삭제·정정·비노출 유지 또는 재개 결정
  -> 양측에 최종 결과 통보
```

- 운영자가 권리자 요청 이메일을 확인하면 자료의 완전성 판단보다 먼저 대상 게시글을 비노출한다.
- 자료가 부족하면 비노출 상태를 유지한 채 보완을 요청한다.
- 요청자 자료는 처리에 필요한 범위에서만 게시 담당자·복제전송자에게 전달한다.

## 4. 저작권 중단·통보·재개

저작권법 제103조 적용 대상인 적법한 중단 요청은 일반 문의와 구분해 처리한다.

1. 요청을 받으면 해당 복제·전송을 즉시 중단하고 권리주장자에게 통보한다. 법령상 대상이면 복제·전송자에게도 통보한다.
2. 중단 통보는 법정 서식과 기한을 따른다.
3. 복제·전송자는 중단 통보 후 법정 기간 안에 정당한 권리를 소명해 재개를 요청할 수 있다.
4. 재개 요청을 인정하면 권리주장자에게 재개 요청 사실과 재개예정일을 지체 없이 통보한다.
5. 법정 범위에서 정한 재개예정일에 공개를 재개한다. 권리주장자가 그 전에 소 제기 사실을 적법하게 통보한 경우에는 재개하지 않는다.

일반 권리 요청은 같은 통보·재검토 원칙을 적용하되 저작권법상 법정 재개 기한을 임의로 적용하지 않는다.

## 5. 결과와 보관

관리자는 요청 내용과 출처를 다시 확인한 뒤 재공개, 수정 후 재공개, 삭제, 비노출 유지, 보완 요청 중 하나를 결정한다. 결과와 적용 시각을 기록하고 필요한 당사자에게 통보한다.

요청 기록은 요청 처리와 필요한 법정 통보·재개 절차가 끝나고 보존 필요가 없어지면 지체 없이 파기한다. 고정 3년 보관은 두지 않는다. 진행 중인 분쟁 또는 법령상 보존이 필요한 최소 자료만 근거·범위·종료 조건을 기록하여 분리 보관한다. 허위 자료나 정당한 권리 없는 반복 요청은 제한할 수 있으나, 그 사유만으로 새로운 적법한 요청을 자동 반려하지 않는다.
