# 회원가입 개인정보 수집·이용 동의

- 문서 상태: 전문 초안 작성 완료, 법무 검토·운영 발행 차단
- 기준일: 2026-09-08
- 정책 유형: `SIGNUP_PRIVACY`
- 운영 버전·시행일: `(미정)`
- 운영자: `[입력 필요: 운영자 표시명]`
- 개인정보 문의: `[입력 필요: 개인정보 문의 이메일]`
- `[출시 차단: 수집·이용 근거와 보존 기간, 연령 확인 방식, 국외이전·수탁자 고지, 전문·버전·시행일의 법무 검토 및 운영값 확정 필요]`

아래 §1–4가 가입 화면에서 보여줄 전문이다. 미확정 운영값과 공개 차단이 남아 있는 동안 실제 동의를 받지 않는다.

## 1. 수집·이용 목적과 항목

블라리요는 회원가입, 로그인, 계정 관리와 회원 기능 제공을 위해 아래 정보를 처리합니다.

| 목적 | 처리 항목 | 보유·이용 기간 |
| --- | --- | --- |
| 소셜 계정으로 가입·로그인 및 연결 관리 | 선택한 소셜 제공자, 제공자별 회원 식별자, 연결·인증 시각 | 계정 연결 해제 또는 탈퇴 처리 완료까지. 외부 해제 처리와 최소 기록의 예외는 §2 참고 |
| 회원 계정 관리 | 내부 회원 번호, 직접 입력한 서비스 표시명, 계정 상태, 가입·최근 로그인 시각 | 탈퇴 처리 완료까지 |
| 가입 연령 판정 | 직접 입력한 생년월일 | 가입 요청에서 연령을 판정한 뒤 즉시 폐기. DB·로그·분석 도구에 보관하지 않음 |
| 연령 판정 및 동의 이력 관리 | 만 14세 이상 판정 통과 시각, 약관·수집이용 동의 버전과 동의 시각 | 탈퇴 처리 완료까지 |
| 로그인 유지와 계정 변경 보호 | 세션 식별자, 최근 재인증 시각 | 로그인 세션은 발급 후 7일 또는 마지막 사용 후 24시간 중 먼저 도래할 때까지. 로그아웃·탈퇴 시 즉시 무효화 |

소셜 제공자에서 이메일·실명·닉네임·사진·성별·생년월일·연령대·전화번호를 추가 요청하지 않습니다.
불가피하게 전달된 불필요한 프로필은 보관하지 않습니다. 생년월일은 직접 입력한 값으로 연령을
계산하기 위한 정보이며 신분증이나 본인확인기관을 통해 검증한 정보가 아닙니다.

## 2. 탈퇴와 예외 처리

탈퇴를 접수하면 로그인 세션과 회원 쓰기 권한을 즉시 중단하고 계정·소셜 연결·동의 기록의 삭제를 시작합니다.
계정 정보는 삭제 작업이 완료되면 파기되며, 처리가 지연되면 운영자가 확인합니다.
외부 제공자의 연결 해제가 늦어져도 로컬 계정 삭제를 진행합니다. 처리 중과 완료 상태는 구분하여 안내합니다.

- 외부 연결 해제에 필요한 암호화 식별정보·자격정보는 분리한 시점부터 최대 24시간, 완료 시 더 일찍 폐기합니다.
- 연결 해제 결과가 불명확하면 재연결 오류를 방지하기 위한 제공자·식별자 변환값·연동 세대·처리 시각을
  계정과 분리하여 최대 30일 보관합니다. 확인이 끝나면 정리하고 기간을 반복 연장하지 않습니다.
- 탈퇴 결과 확인 정보는 처리 완료 후 24시간까지 보관합니다.
- 백업은 일별 14일·주별 8주 순환으로 삭제합니다. 계정 연결이 복원되지 않도록 최소 내부 참조·처리 시각·
  처리 정책을 암호화한 복원용 삭제 기록은 8주 보관하며, 복원 시 먼저 삭제 처리를 재적용합니다.
- 법령에 따라 별도 보존이 필요한 경우에는 해당 근거·항목·기간을 별도로 고지합니다.
  현재 확정되지 않은 법적 보존 사유를 근거로 모든 회원 정보를 무기한 보관하지 않습니다.

익게에 작성한 글·댓글은 탈퇴로 자동 삭제되지 않으며 계정 연결을 제거하고 유지합니다.
본문에 직접 적은 개인정보까지 자동으로 제거되는 것은 아닙니다. 탈퇴 전 본인 수정·삭제 기능을
이용할 수 있으며, 탈퇴 후에는 일반 회원 편집 대신 개인정보·권리 침해 요청 채널을 이용할 수 있습니다.
회원 참여 시의 작성자 연결·신고·제재 및 보안 로그에 대한 상세 처리는 [개인정보처리방침](privacy-policy.md)을 확인해 주세요.

## 3. 동의를 거부할 권리

위 개인정보 수집·이용에 동의하지 않을 권리가 있습니다. 동의하지 않으면 회원가입과 회원 참여 기능을
이용할 수 없습니다. 로그인 없이 제공되는 공개 콘텐츠는 계속 열람할 수 있습니다.
만 14세 미만은 가입할 수 없습니다. 가입 후 동의를 철회하려면 계정 화면에서 탈퇴를 신청할 수 있습니다.

## 4. 동의 항목

`[필수] 회원가입 개인정보 수집·이용에 동의합니다.`

이 항목은 이용약관 동의와 별도로 받습니다. 마케팅·분석·광고 동의는 포함하지 않습니다.
문의는 위 개인정보 문의 연락처를 이용해 주세요.

## 5. 발행·화면 연결 계약

- 필수 동의 전에 전체 전문을 열람할 수 있어야 한다. 전문 링크 열기만으로 동의 처리하지 않는다.
- 정책 API `/api/v1/policies/signup-privacy`와 가입 화면의 policy viewer에서 동일 artifact를 사용한다.
  실제 DB 정책 ID·버전·시행일은 발행 시 부여하고 초안 날짜를 시행일로 사용하지 않는다.
- Core는 현재 EFFECTIVE인 TERMS와 SIGNUP_PRIVACY를 각각 검증하고 계정 생성과 동의 기록을 원자적으로 저장한다.
  전문 개정 중 제출하면 최신 전문을 표시하고 필수 체크를 초기화한다. 기존 회원 재동의에 생년월일을 다시 요구하지 않는다.
- 소셜 인증 임시 정보는 이 화면의 동의 전에 수신될 수 있으므로 로그인 진입 화면의 사전 안내·처리 근거는
  별도 법무 검토한다. 가입 완료 전 10분 TTL과 취소 시 파기 계약은 그대로 유지한다.
- §2의 보존 기간은 현재 기술 설계값이다. 근거 적정성·실제 삭제 가능성을 확인한 후 발행한다.
- 작성 근거: [개인정보 보호법 제15조 제2항](https://www.law.go.kr/LSW/lsLawLinkInfo.do?chrClsCd=010202&lsJoLnkSeq=900079620)의 목적·항목·기간·거부권 고지 항목.
  본 초안 작성은 법무 검토 완료를 의미하지 않는다.
