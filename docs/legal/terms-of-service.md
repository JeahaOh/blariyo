# 블라리요 이용약관 초안

- 문서 상태: 초안
- 시행일: `[입력 필요]`
- 서비스명: `블라리요`
- 운영자: `[입력 필요]`
- 문의: `[입력 필요]`

## 제1조 목적

이 약관은 운영자가 제공하는 블라리요 웹 서비스의 이용 조건, 운영자와 이용자의 권리·의무, 서비스 이용 절차, 게시물 처리 기준, 책임 범위를 정하는 것을 목적으로 한다.

## 제2조 용어의 정의

1. `서비스`란 블라리요가 제공하는 유머 게시글 목록, 게시글 상세, 공유, 권리자 요청 접수, 쿠키 설정 등 웹 기반 기능을 말한다.
2. `이용자`란 회원가입 여부와 관계없이 서비스를 방문하거나 이용하는 사람을 말한다.
3. `게시글`이란 운영자가 등록한 제목, 본문, 이미지, 출처 정보, 기타 부가 정보를 말한다.
4. `출처`란 게시글 작성 또는 큐레이션 과정에서 참고한 원본 사이트명, URL, 작성자 표시 등 원천 정보를 말한다.
5. `제휴 콘텐츠`란 외부 상품 또는 서비스로 이동하는 링크가 포함되고, 수수료 발생 가능성이 고지되는 콘텐츠를 말한다.

## 제3조 약관의 게시와 변경

1. 운영자는 이 약관을 서비스 하단 또는 별도 약관 화면에 게시한다.
2. 운영자는 관련 법령을 위반하지 않는 범위에서 약관을 변경할 수 있다.
3. 중요한 변경은 시행일 전 서비스 화면에 공지한다.
4. 변경 약관은 공지한 시행일부터 적용한다.

## 제4조 서비스의 제공

운영자는 다음 기능을 제공할 수 있다.

1. 운영자가 선별한 게시글 목록
2. 게시글 상세 열람
3. 게시글 공유
4. 출처 확인과 원문 이동
5. 권리자 요청 접수
6. 쿠키와 분석 설정
7. 광고 또는 제휴 콘텐츠 표시

## 제5조 서비스의 변경과 중단

1. 운영자는 서비스 개선, 운영상 필요, 장애, 보안 이슈, 법령 준수를 위해 서비스 일부 또는 전부를 변경하거나 중단할 수 있다.
2. 예정된 중단은 가능한 범위에서 사전에 공지한다.
3. 긴급 장애, 보안 사고, 외부 인프라 장애는 사전 공지 없이 처리할 수 있다.

## 제6조 이용자의 의무

이용자는 다음 행위를 해서는 안 된다.

1. 서비스의 정상 운영을 방해하는 행위
2. 자동화 도구로 과도하게 요청하는 행위
3. 게시글, 이미지, 화면, 데이터를 무단 수집·복제·배포하는 행위
4. 타인의 권리, 명예, 사생활을 침해하는 행위
5. 보안 취약점 탐색 또는 우회 행위
6. 법령 또는 공서양속에 반하는 행위

## 제7조 게시글 운영 기준

1. M0 게시글은 운영자가 등록한다.
2. 운영자는 게시글의 출처와 권리 상태를 발행 전에 확인한다.
3. 권리 침해 가능성, 부정확한 출처, 운영 정책 위반이 확인되면 게시글을 수정, 숨김, 삭제할 수 있다.
4. 게시글의 원문이 변경·삭제되거나 권리자 요청이 접수된 경우 운영자는 게시글을 비노출할 수 있다.

## 제8조 출처와 권리자 요청

1. 외부 콘텐츠를 참고한 게시글은 가능한 범위에서 출처를 표시한다.
2. 출처 표시는 권리 확보를 의미하지 않는다.
3. 권리자는 `권리자 요청 안내` 화면에 따라 게시 중단 또는 정정을 요청할 수 있다.
4. 운영자는 접수 내용을 검토한 뒤 필요한 조치를 한다.

## 제9조 광고와 제휴 콘텐츠

1. 서비스에는 광고가 표시될 수 있다.
2. 제휴 콘텐츠에는 외부 사이트 이동과 수수료 발생 가능성을 표시한다.
3. 광고 차단이 감지될 경우 광고 차단 해제 요청 안내가 표시될 수 있다.
4. 광고 또는 제휴 링크의 외부 사이트 이용에는 해당 외부 사이트의 정책이 적용된다.

## 제10조 개인정보 보호

운영자는 개인정보 처리와 쿠키 사용에 관한 사항을 `개인정보처리방침`과 `쿠키 설정 안내`에 게시한다.

## 제11조 책임의 제한

1. 운영자는 천재지변, 장애, 외부 서비스 문제 등 운영자의 합리적 통제 범위를 벗어난 사유로 발생한 서비스 중단에 대해 책임을 제한할 수 있다.
2. 이용자가 외부 링크로 이동해 이용한 서비스, 상품, 콘텐츠에 대해서는 해당 외부 제공자의 정책이 적용된다.
3. 운영자는 이용자가 서비스를 이용해 기대한 특정 효과를 보장하지 않는다.

## 제12조 분쟁 해결

1. 운영자와 이용자는 분쟁이 발생한 경우 성실히 협의한다.
2. 협의가 어려운 경우 관련 법령에서 정한 관할과 절차에 따른다.

## 제13조 부칙

이 약관은 `[입력 필요]`부터 시행한다.
