# 블라리요 이용약관 초안

- 문서 상태: 출시 전 확정 필요
- 시행일: `[출시 차단: 시행일 입력 필요]`
- 서비스명: `블라리요`
- 운영자: `[출시 차단: 운영자명·사업자 정보 입력 필요]`
- 문의: `[출시 차단: 문의 이메일 입력 필요]`

위 항목이 확정되기 전에는 production에 공개하지 않는다.

## 제1조 목적과 정의

이 약관은 블라리요의 이용 조건과 운영자·이용자의 권리·의무를 정한다.

1. `서비스`는 게시판의 목록·상세·공유·정책 기능을 말한다.
2. 초기 게시판은 표시명 `짤`, 코드 `meme`, URL `/meme`이며 `/`는 `/meme`으로 이동한다. 운영자는 이후 게시판을 추가하거나 변경할 수 있다.
3. 초기 게시글은 관리자가 직접 선별하고 외부 콘텐츠에는 출처를 표시한다.
4. `제휴 콘텐츠`는 링크를 통한 거래로 운영자가 수수료를 받을 수 있음을 명시한 콘텐츠다.

## 제2조 약관 게시와 변경

운영자는 약관을 `/terms`와 푸터에 게시한다. 중요한 변경은 시행일 전에 알리고 시행일부터 적용한다.

## 제3조 서비스 제공

1. 공개 목록은 광고 행을 제외한 게시글 20개를 제공한다.
2. 상세 하단은 현재 글과 같은 게시판의 현재 글 주변 게시글 20개를 제공한다.
3. 운영자는 공유, 출처 확인, 권리자 요청, 쿠키 설정, 광고·제휴 기능을 단계적으로 제공할 수 있다.
4. 자동 수집 결과는 임시 후보 큐에만 저장하며 운영자가 확인하고 발행하기 전에는 공개하지 않는다.

## 제4조 서비스 변경과 이용자 의무

운영자는 개선, 장애, 보안, 법령 준수를 위해 서비스를 변경·중단할 수 있다. 이용자는 과도한 자동 요청, 무단 수집·복제·배포, 권리 침해, 보안 우회, 위법 행위를 해서는 안 된다.

## 제5조 게시글과 권리자 요청

1. 외부 콘텐츠에는 출처를 표시하지만 출처 표시는 권리 확보를 뜻하지 않는다.
2. 권리자 요청이 접수되면 대상 게시글을 우선 비노출하고 관리자가 요청 내용과 출처를 다시 확인한다.
3. 관리자는 검토 결과에 따라 게시글을 재공개·수정·삭제할 수 있다.
4. 재개 요건이 충족되면 재개 사실과 예정일을 통보한 뒤 공개할 수 있다. 저작권법상 중단·재개 요청은 [권리자 요청 안내](./rights-request.md)의 법정 절차를 따른다.

## 제6조 광고와 제휴

1. 상세 광고는 본문·출처 다음, 하단 목록 중간, 목록 아래에만 둘 수 있다.
2. 광고 호출 실패와 확정 차단을 구분하며, 어느 경우에도 게시글 열람을 제한하지 않는다.
3. 제휴 링크가 있는 게시글은 본문 시작 전과 링크 가까운 위치에 `제휴` 또는 `광고` 표시와 수수료 수취 사실을 명확히 고지한다.
4. 쿠팡 파트너스 사용 시 해당 프로그램이 요구하는 고지 문구를 눈에 띄게 표시한다. `[출시 차단: 제휴 사업자·필수 문구·수수료 구조 확정 필요]`
5. 광고·제휴 링크로 이동한 외부 서비스에는 해당 제공자의 정책이 적용된다.

## 제7조 개인정보 보호

필수 내부 운영 통계와 선택 GA4·광고의 처리 기준은 [개인정보처리방침](./privacy-policy.md)과 [쿠키 설정 안내](./cookie-settings.md)에 공개한다. 분석·광고 동의를 거부하거나 철회해도 공개 콘텐츠 열람을 제한하지 않는다.

## 제8조 책임과 분쟁 해결

운영자는 합리적 통제 밖의 장애와 외부 서비스 문제에 대해 관련 법령 범위에서 책임을 제한할 수 있다. 분쟁은 우선 성실히 협의하고, 해결되지 않으면 관련 법령의 관할과 절차를 따른다.

## 제9조 부칙

이 약관은 `[출시 차단: 시행일 입력 필요]`부터 시행한다.
