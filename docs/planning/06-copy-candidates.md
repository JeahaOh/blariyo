# Blariyo 카피 후보 보류 문서

- 문서 상태: 카피 결정 보류, 4차 감사 정합성 확인
- 기준일: 2026-08-12
- 관련 문서: [01-service-plan.md](./01-service-plan.md), [03-screen-design.md](./03-screen-design.md), [05-benchmark-spec.md](./05-benchmark-spec.md)
- 서비스 명칭: `블라리요`

## 1. 목적

서비스명은 `블라리요`로 확정한다. 메인 슬로건, 서브 카피, OG title, OG description은 아직 확정하지 않고 이 문서에서 후보로만 관리한다.

기획서와 와이어프레임에는 특정 문구를 최종안처럼 고정하지 않는다. 최종 카피는 홈 첫인상, 공유 미리보기, 출퇴근길 사용 맥락을 함께 보고 별도 결정한다.

## 2. 카피 판단 기준

- 출퇴근길, 이동 중, 짧은 틈에 보는 맥락이 바로 읽혀야 한다.
- 너무 뉴스, 블로그, 큐레이션 매거진처럼 보이면 제외한다.
- 과하게 센 척하거나 유행어에 기대는 문구는 오래 버티기 어렵다.
- OG 문구는 카카오톡, X/Twitter, 메신저 미리보기에서 잘려도 의미가 남아야 한다.
- 홈 문구와 공유 문구는 같을 필요가 없다. 홈은 행동 유도, OG는 클릭 이유를 우선한다.

## 4. 적용 보류 범위

최종 결정 전까지 아래 위치에는 임시 문구를 넣거나, 와이어프레임에서는 문구 자리를 표시하는 수준으로 둔다.

- 홈 헤더 보조 문구
- 홈 title과 description
- 홈 OG title과 OG description
- 게시글 상세 공유 기본 문구
- 푸터 브랜드 한 줄 설명
- 광고 차단 안내의 브랜드 문장

## 5. 현재 판단

현재 방향과 가장 가까운 후보는 A다. 다만 최종 확정은 보류한다.

A는 출퇴근 맥락이 가장 직접적이고, 서비스명을 자연스럽게 노출한다. 단점은 다소 평이하다는 점이다.

B와 C는 부드럽고 공유 미리보기에는 안정적이다. 단점은 브랜드명이 약하게 남는다.

D는 연속 소비를 잘 표현하지만, 서비스의 기본 첫인상으로는 약간 가볍다.

E는 퇴근길에 치우쳐 출근길 맥락이 빠질 수 있다.

## 6. 4차 감사 정정 결과

카피 보류는 제품·IA·데이터·API 결정을 보류한다는 뜻이 아니다. 게시판은 `유머`, `이야기` 두 개이며 `/`는 별도 세 번째 메뉴 없이 두 게시판의 혼합 최신 목록으로 확정한다. 목록 수, 상세 주변 목록, 광고 위치, 수집·검수·초안·발행 상태와 API는 [01-service-plan.md](./01-service-plan.md)와 [05-benchmark-spec.md](./05-benchmark-spec.md)를 따른다.

최종 결정 전까지 보류하는 것은 슬로건, 홈 보조 문구, 홈·상세 공유 카피뿐이다. 카피 후보가 확정된 IA나 API 명칭을 바꾸는 근거로 사용돼서는 안 된다.
