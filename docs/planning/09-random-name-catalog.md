# 글별 랜덤 이름 사전과 조합 규칙

- 상태: 설계용 초도 사전 작성 완료, 단어 검토·전체 조합 기계 검사 완료, 구현·전체 문구별 사람 검수 미실행
- 기준일: 2026-09-08
- 제품 정본: [회원·익게](08-member-community-plan.md#7-랜덤-이름의-범위와-표현)
- 배정·저장: [기술 계약](../system-design/06-member-community-design.md#random-name-assignment)

## 1. 조합

`장소·상황 + 공백 + 수식어 + 공백 + 명사`를 사용한다. 초도 사전은 32 × 64 × 128로
금칙 조합 제외 전 262,144개다. 예: `달빛 아래 느긋한 수달`, `공방의 그림 그리는 푸딩`,
`무지개 아래 탐험하는 오카리나`. 이름은 우스꽝스러운 비유를 허용하지만 특정 사람의 특성을 묘사하지 않는다.

## 5. 확대와 금칙 기준

- 확대 목표는 장소·상황 128개, 수식어 256개, 명사 512개로 16,777,216개 조합이다.
  이는 추가 검수 후의 목표이며 현재 확보한 단어 수가 아니다. 각 범주를 균형 있게 늘리고 동의어만으로 채우지 않는다.
- 사람의 실명·상표·유명 캐릭터·기관명, 관리자/운영자/공식/글쓴이 사칭 표현, 성적·혐오·비하·폭력 표현,
  질병·장애·인종·국적·종교·정치 성향·성별·연령을 평가하는 조합은 배정 대상에서 제외한다.
- 단어와 완성 조합 모두 검토한다. 조합 금칙은 정규화된 전체 이름 또는 단어 ID 쌍/삼중 조합으로 관리한다.
  허용 목록 방식이며 외부 사전 자동 유입·런타임 자유 생성은 사용하지 않는다.
- 구현 시 사전 manifest에 버전·단어 수·금칙 규칙·제외 후 실제 후보 수·체크섬을 기록한다.
  이번 조합 수 검사는 문법·길이·중복 검사이며 모든 표현의 적절성을 보증하지 않는다.
- 같은 글 중복 및 같은 계정의 다른 글 이름 재사용은 기술 계약의 제약으로 방지한다.
  다른 회원끼리는 다른 글에서 같은 이름이 나올 수 있다. 계정 삭제 후 과거 이름을 재가입 계정에 연결하지 않는다.
- 신규 사전은 중복·공백·Unicode NFC 정규화·32 Unicode code point 제한·금칙어 검사를 거쳐 배포한다.
  잘못된 사전을 되돌려도 이미 부여한 label은 유지한다. 부적절한 기존 표시가 발견되면 해당 콘텐츠를
  숨기고 운영 검토하며 자동 이름 교체로 해결하지 않는다.

## 6. 초도 사전 검수 결과 (2026-09-08)

- 장소·상황 32개, 수식어 64개, 명사 128개를 문맥 검토했다. 실명·민감 특성·사칭을 직접 표현하는
  단어는 없으며 무생물의 행동 표현은 의도된 의인화로 허용했다. 단어만 검토한 결과를 전체 문구의 사람 검수로 확대하지 않는다.
- 전체 262,144개를 실제 조합해 중복, NFC, 한글·공백 외 문자, 32 Unicode code point 한도와 명시 금칙어를 검사했다.
  중복·형식·금칙어 검출 0건, 최대 길이 19 code point. 명시 목록 밖의 은어·시대적 맥락까지 안전하다는 보증은 아니다.
- 재현: `python3 docs/system-design/validation/check-member-design.py`.
  금칙어 목록과 검증 범위는 [검증 스크립트](../system-design/validation/check-member-design.py)에 공개한다.
- 신고·새로운 의미 변화로 부적절한 조합이 확인되면 §5에 따라 후보에서 제외한다.
