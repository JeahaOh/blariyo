# 콘텐츠 수집 아이디어 백로그

확정 요구사항과 구분하여 보관하는 후속 검토 목록이다. 등록만으로 구현·수집 범위를 변경하지 않는다.
현행 정책은 [콘텐츠 수집 기획](README.md)을 따른다.

## COL-IDEA-01 — 베스트 댓글 캡처를 본문에 함께 저장

- 등록일: 2026-10-06
- 상태: 아이디어 보관 · 구현 미승인
- 우선순위·일정: (미정)
- 사용자 제안: 각 게시글을 스크랩할 때 해당 글의 베스트 댓글을 Playwright(브라우저 자동화 도구)로 별도 캡처하고, 캡처 이미지를 우리 게시글 본문에 함께 저장한다.
- 기대 효과: 원문 내용과 주요 댓글 반응을 함께 볼 수 있다.
- 흐름 초안: 원문 수집 → 베스트 댓글 영역 표시/캡처 → 수집물에 연결 → 관리자 검수 → 승인 시 본문에 함께 반영. 삽입 위치와 자동 포함 여부는 아직 확정하지 않는다.

### 구체화할 때 확인할 사항

- 출처별 베스트 댓글 선정 기준, 캡처할 개수·영역, 댓글 없음·접힌 댓글·추가 로딩 처리.
- 닉네임·프로필 이미지 등 표시 범위, 재게시 권리와 삭제 요청 처리.
- 캡처 이미지의 가독성·모바일 표시, 원문 URL·캡처 시각·댓글 식별 정보 연결, 저장 용량과 보존 기간.
- 브라우저 실행 비용·요청 간격·동시 실행 수, 캡처 실패가 원문 수집과 검수에 미칠 영향.
- 검수 화면에서 댓글 캡처를 확인하고 제외할 수 있는지, 원문 댓글 수정·삭제 이후 동기화 범위.

### 현행 정책과의 관계

현재 수집 기획은 댓글을 파싱된 본문과 공개 결과에서 제외한다. 이 아이디어는 그 정책의 변경 후보이며,
현재 수집 동작은 유지한다. 구현 결정 시 댓글 포함 범위와 기획·저장/API·검수 화면 계약을 먼저 구체화한다.
