# Blariyo responsive publishing prototype

- 목적: 와이어프레임 이후 실제 화면 밀도, 여백, 반응형 동작을 확인하는 정적 퍼블 파일
- 기준: 데스크톱·모바일 웹만 검토
- 실행: `index.html`을 브라우저에서 직접 열어 확인

## 파일

| 파일 | 역할 |
| --- | --- |
| `index.html` | 홈, 상세, 상태 화면 markup |
| `styles.css` | 반응형 layout, 게시판 목록, 광고, 상세 본문 스타일 |
| `app.js` | 화면 전환과 20개 목록 샘플 렌더링 |

## 현재 반영 기준

- 홈 목록은 페이지당 20개
- 상세 하단 목록도 페이지당 20개
- 상세 출처는 본문 하단에 1회만 표시
- 상세 광고는 본문 하단 1개, 하단 목록 안 1개, 하단 목록 아래 1개
- 이전글/다음글 별도 버튼 없음
- 모바일은 `번호 / 제목 / 시간` 중심으로 단순화
