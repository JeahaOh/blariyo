# 게시판·콘텐츠 운영 정책 정정

- 작성일: 2026-08-12
- 상태: 현행 결정
- 정본: [01-service-plan.md](../planning/01-service-plan.md)

## 확정 사항

- 콘텐츠 선별 기준은 `관리자가 보기에 웃긴 것`이다.
- 외부 콘텐츠에는 출처를 표시한다.
- 출처 표시는 권리 확보를 뜻하지 않는다.
- 권리자 요청이 접수되면 대상 글을 먼저 숨기고 관리자가 재공개·수정·삭제를 판단한다.
- 하루 2회, 회당 10~20개를 게시한다.
- 외부 이미지는 블라리요 서버 측 저장소에 저장한다.
- 실제 이미지 저장 사업자와 물리 경로는 미정이다.

## 게시판과 URL

| 공개 순서 | 표시명 | 내부 코드 | URL |
| --- | --- | --- | --- |
| 초기 | 짤 | `meme` | `/meme` |
| 추후 | 익게 | `community` | `/community` |
| 추후 | 뉴스 | `news` | `/news` |

- `/`는 `/meme`으로 리다이렉트한다.
- 초기에는 `짤`만 공개한다.
- 게시판은 데이터 기반으로 더 추가할 수 있다.
- 익게와 뉴스의 세부 기능은 실제 개발 전에 별도 결정한다.
