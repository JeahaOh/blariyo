# Blariyo 세션 기록

프로젝트 작업을 다시 시작할 때 필요한 결정과 상태를 날짜별로 기록한다.

현재 게시판·운영 정책 정본: [2026-08-12-board-policy-correction.md](./2026-08-12-board-policy-correction.md)

## 정본 우선순위

- 세션 기록은 당시의 판단과 작업 상태를 보존하는 이력이며 현행 기획 정본이 아니다.
- 현행 요구사항은 `docs/planning/`의 정본 문서와 가장 최근의 정정·결정 문서를 우선한다.
- 이전 세션과 최신 정본이 충돌하면 최신 정본을 적용하고, 이전 세션 본문을 소급 수정하지 않는다.
- 대체된 세션 문서 상단에는 `대체됨 · 과거 비교용` 표시와 현행 정본 링크를 둔다.
- 구현 여부는 세션 기록이 아니라 실제 소스, migration, 테스트와 Git 이력으로 확인한다.

## 파일명

```text
YYYY-MM-DD-short-topic.md
```

같은 날짜에 주제가 다르면 파일을 나누고, 같은 작업을 이어가면 기존 파일에 내용을 추가한다.

## 기록 항목

1. 세션 목적
2. 확정한 결정
3. 작성·변경 파일
4. 검증 결과
5. 남은 작업
6. 다음 세션 시작점

소스 코드의 상세 diff를 복사하지 않는다. 구현 상태는 Git과 테스트 결과를 기준으로 하고, 세션 기록에는 다음 작업에 필요한 요약만 남긴다.
