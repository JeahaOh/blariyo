공개 전 확인할 것

아래는 기능 미정이 아니라 M1.5 공개 조건과 첫 버전 제외 범위다.

회원 참여 gate

실제 provider 등록·callback·secret, 필수 동의 artifact와 회원 상태 검증이 끝나야 작성·댓글·신고를 공개한다.

법무·운영 근거

신고·제재 보존 근거와 기간, 약관 고지, 운영자 처리 가능 여부를 검토한다. 설계값만으로 공개하지 않는다.

첫 버전 제외

공지, 검색, 이미지, 예약, 초안 저장, 추천·비추천, 랭킹, 쪽지, 팔로우와 대댓글은 M1.5 첫 버전에 넣지 않는다.

확정된 참여·운영 규칙

본인 글·댓글만 수정·삭제하며, 신고는 자동 숨김이 아니다. 운영자는 검토 뒤 숨김·복원·삭제·제재를 처리한다.
