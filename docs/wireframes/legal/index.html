이용약관

시행일 `[입력 필요]`

서비스 이용 조건, 게시글 운영 기준, 광고·제휴 콘텐츠, 책임 범위를 조항형으로 안내한다.

핵심 구성

  1. 목적과 용어
  2. 서비스 제공과 중단
  3. 이용자 금지 행위
  4. 게시글 운영과 권리자 요청
  5. 광고와 제휴 콘텐츠
  6. 책임 제한과 분쟁 해결

UI 규칙

상단에는 제목과 시행일을 두고, 본문은 조항 단위 접힘 없이 한 페이지에서 스크롤한다. 모바일에서도 약관 검색 없이 읽히도록 조항 제목을 크게 둔다.

개인정보처리방침

시행일 `[입력 필요]`

수집 항목, 처리 목적, 보유 기간, 제3자 제공, 위탁, 쿠키, 권리 행사, 보호책임자를 표로 먼저 보여준다.

요약 표

직접 회원 정보M0에서는 회원가입 없음
자동 생성 정보IP, User-Agent, 접속 일시, 요청 URL
선택 정보분석 동의, 광고 동의, 권리자 요청 정보
보유 기간로그 90일, 동의 기록 12개월, 권리자 요청 3년

UI 규칙

개인정보 화면은 표와 조항을 함께 쓴다. 사용자가 가장 많이 찾는 수집 항목, 보유 기간, 문의처를 상단 1스크린 안에 배치한다.

권리자 요청

게시 중단·정정 요청

저작권, 초상권, 개인정보, 명예 등 권리 침해 가능성이 있는 게시글의 중단·수정 요청 방법을 안내한다.

요청 정보

  1. 요청자 이름 또는 단체명
  2. 연락 이메일
  3. 게시글 URL
  4. 침해 권리와 사유
  5. 권리 소명 자료
  6. 원하는 조치

처리 흐름

접수 → 대상 확인 → 권리 소명 확인 → 임시 비노출 또는 유지 판단 → 처리 결과 회신 순서로 보여준다.
