# M0 운영 인수 문서 가독성 정리

## 요청

- `docs/operations/m0-operation-handoff.md`가 Codex 내부 용어 중심이라 실제 운영자가 이해하기 어렵다는 지적을 받았다.
- 액션 문장을 운영자가 직접 실행 가능한 형태로 바꾼다.

## 변경

- 첫 섹션을 `먼저 할 일`로 바꾸고, 실제 다음 행동 5개를 순서대로 제시했다.
- 내부 코드명은 본문 주어가 아니라 보조 용어 표로 이동했다.
- 각 작업을 목적, 실행, 통과 기준, 기록 양식으로 재구성했다.
- 수집 출처 S1~S5는 운영자 질문 형태로 풀어썼다.
- 중단 기준을 별도 섹션으로 모아 실제 운영 중 멈춰야 할 조건을 명확히 했다.
