# 운영자 콘텐츠 선별 패턴 검토

- 요청: 본인이 수집·발행한 글의 선별 기준에 규칙성이 있는지 검토. RPi 이전은 추후 고려 방향이며 현재 이전 작업은 요청하지 않음.
- 담당: Codex / 상태: 종료 / 갱신: 2026-10-10 09:02 KST.
- 작업 폴더: `/Volumes/MicroVault/iCloudDrive/git/private/blariyo`, 브랜치: `feature/discord-review`, 기준 HEAD `6990dea`.
- 담당 경로: 이 기록 폴더만. 직전 담당 종료 확인, 기존 변경·과거 기록 보존.
- 범위: 운영 DB를 READ ONLY로 조회해 직접 승인·발행한 글의 출처/소재/형식과 명시적 반려 기록을 비교한다. 미검수/자동 만료 반려를 선호도와 동일시하지 않는다. 제목만으로 이미지 내용을 확정하지 않는다.
- 비밀·actor/operator 원문·개인 계정 ID·원시 요청 body는 출력하지 않는다. 운영 쓰기·코드 변경·수집 실행·발행·설정 변경·Git 반영 없음.

## 확인 범위와 수치

- 운영 READ ONLY transaction/statement_timeout와 SSH host key/hostname 검사를 유지했다. [조회 코드](read-server.py), [운영 읽기 결과](production-readback.jsonl), [요약 수치](summary.json).
- 현재 공개102건 중 직접 Discord 승인·발행23건, 직접 Discord 반려23건을 주 분석 대상으로 삼았다. 승인/반려 각각 operator_count=1이며 계정 원문은 출력하지 않았다. 명령 없는 이전/수동/테스트79건은 선호 표본에 섞지 않았다. 자동 만료 반려51건도 제외했다.
- 이 직접 승인 표본의 실제 발행일은10/08~10/09 KST. 승인 출처: 더쿠11/율도9/오늘의유머3. 반려 출처: 율도15/더쿠6/네이트판2. 제공·미검수 후보 전체 분모가 없어 출처 취향 순위로 해석하지 않는다.
- 발행23건 중 이미지 포함19건(82.6%), 이미지 없는4건(17.4%). 반려23건 중 이미지 포함7건(30.4%), 이미지 없음16건(69.6%). 반려12건은 저장된 본문이 LINK만 존재했다.

## 관찰과 해석

- 가장 뚜렷한 형식 차이: 발행에는 이미지 포함이 많고 반려에는 LINK-only가 많다. 외부 링크로 나가야 내용이 보이거나 SNS 수집이 누락된 후보를 거를 가능성이 있다. 반려 이유의 설명은 저장돼 있지 않아 인과를 확정하지 않는다.
- 제목/주제 중복2쌍: 김우영 작가 별세는 더쿠 발행/율도 반려. 전세계 여자들 관련 트윗은 율도 발행/더쿠 반려. 중복 정리 가설에 부합하지만 원문 이미지 동일성·반려 당시 의도는 확인하지 않았다.
- 제목·저장 텍스트상 생활 공감/불합리한 상황/의외성/최근 이슈가 함께 발행됐다. 커피 가격, 버거킹 쿠폰, 점심시간 권리, 술값 논쟁, 편도39km 발령, AI 조언 이별/퇴사, 위고비 건강보험 기사 등이다. 이는 분석자의 잠정 분류이며 확정 편집 정책이 아니다.
- 네이버페이 포인트 모음2건이 모두 반려돼 포인트 수집용 링크 나열에 낮은 우선순위를 주는 가설이 있다. 표본2건이므로 일반 광고/브랜드 전부 금지로 확대하지 않는다.
- 치이카와 관련5건 반려는 모두 LINK-only다. 팬덤 소재를 싫어한다고 단정할 수 없고 수집/표시 누락 영향을 먼저 분리해야 한다.
- 이미지 필수/짧은 글만/순수 유머만이라는 강제 기준은 보이지 않는다. 이미지 없는 기사·SNS 링크4건도 승인했고, 영화관 글 이미지16장과 프랑스 상황 글 TEXT21블록도 발행했다. 시사·연예·감동 소재도 포함돼 있다.
- planning의 현행 기준은 여전히 `관리자가 보기에 웃긴 것`(docs/planning/01-service-plan.md §3). 이 관찰을 정본/자동발행/자동반려 규칙으로 적용하지 않았다.

## 검증·잔여

- 최초 psql json_agg 결과는 여러 줄 JSON이었다. JSONDecoder.raw_decode로 모든 문서를 읽고 유효한 JSONL로 정규화했다. 수치와 개별 사례를 원문 결과와 재대조했다. git diff --check 및 기록 링크 존재 확인 통과.
- 제목·저장 텍스트·블록 형식 및 현재 결정만 확인. 전체 이미지 시각 검토·과거 반려 이유·개인 취향의 인과는 미검증. 표본23/23으로 일반 규칙 확정에는 부족하다.
- 운영/개발 DB 쓰기·코드/설정 변경·수집/발행 실행·Git 반영 없음. 향후 RPi 이전 고려는 이번 요청 맥락으로 기록만 남기며 일정/구현을 확정하지 않았다.
