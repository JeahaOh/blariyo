# Blariyo 작업 기록

이 디렉터리는 기획·설계 정본과 분리한 비정본 작업 이력이다.

- `task-list/`: 작업 범위, 검증 결과, 패치와 핸드오프
- `session-log/`: 날짜별 결정, 상태 요약과 다음 시작점

현행 제품 요구사항은 `docs/planning/`, 기술 계약은 `docs/system-design/`, 법무 문서는
`docs/legal/`을 우선한다. 작업 기록과 정본이 충돌하면 정본을 기준으로 판단한다.

2026-08-19에 기존 `docs/task_list/`와 `docs/session-log/`를 이 위치로 옮겼다.
이동 전의 Git 상태나 당시 경로를 증거로 기록한 문장은 과거 사실 보존을 위해 그대로 둘 수
있으며, 새 작업과 현재 파일 링크는 `worklog/` 경로를 사용한다.
