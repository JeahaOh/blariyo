## 변경과 판단

- [M0 정책 원문](../../../../../docs/legal/m0-core/README.md) 네 종류와 상위 법무 문서의 최초 시행일을

- 문의 1년·권리 요청 3년의 일괄 보관을 없앴다. 처리 목적과 필요한 법정 절차가 끝나면
  지체 없이 파기하고, 분쟁·법령상 보존이 필요한 최소 자료만 별도로 관리한다.

- 법정 개인정보처리시스템 접속기록은 일반 방문·오류 로그와 구분한다. 안전성 확보조치 기준
  제8조의 1년·2년 요건을 반영했다. 해당 요건을 만족하는 기록 수집·보관이 완료됐다는 뜻은 아니다.
- 기존 Cloudflare 대시보드의 활성 메일 전달 규칙에서 Email Routing → 일반 Gmail을 확인했다.
  이메일·목적지 주소 원문은 기록하지 않았다. 일반 Google 한국 약관의 제공자는 Google LLC다.
- 이전 초안은 수정하지 않고 새 편집본에 `v0.1-draft.2`를 사용한다. 초기화 입력 도구도 새 버전을 사용한다.

## 실제로 남은 사항

1. **기간 삭제 설정**: 서버 Compose의 Docker `max-size`·`max-file`은 용량 제한이다.
   7일 삭제를 구현·검증하지 않았으므로 고지한 기간이 운영 중이라고 표시하지 않는다.
2. **외부 처리 고지**: 메일 전달 경로는 확인했으나 Cloudflare·Google 등의 실제 처리 국가,
   사업자 보존과 국외이전 고지에 필요한 항목은 남아 있다. 국내 서버라는 이유로 국내 처리만 한다고 쓰지 않는다.
3. **정식 공개**: 남은 본문 조건을 해소해 `v0.1` 발행 → Core·Web 기동 → 실제 정책 화면·관리자 인증 확인 → Tunnel 연결.
   관리자 쿠키 실화면, 원격 백업·복원 및 삭제 재적용도 아직 운영 검증이 필요하다.

시행일 확정은 정책 발행 완료를 뜻하지 않는다. 개인정보 본문의 남은 placeholder는 삭제하지 않았다.
기존 DRAFT를 EFFECTIVE로 직접 바꾸거나 production 기동 검사를 우회하지 않았다.
기존 DB 데이터·migration·Tunnel·Nginx·비밀번호는 보존했다. commit/push 없음.
공식 법령·사업자 근거는 M0 정책 README에 연결했다.
