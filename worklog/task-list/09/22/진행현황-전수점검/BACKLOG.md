## CI/CD 자동 배포의 위치

GitHub Actions 기반 자동 CD는 사용자 후속 TODO다. 현재 정책은 검증된 image를 만들되 운영 배포는 수동 실행으로 분리한다(`docs/implementation/operations/deployment-policy.md:47-61`). 따라서 자동 CD는 M0 필수 수용 조건으로 올리지 않는다. 사용자가 후속 작업을 승인하면 `TODO-CICD-DEPLOY.md:15-45`의 production 승인, digest pull, readiness, rollback 조건을 별도 작업으로 수행한다.

## 수용 순서

P0는 현행 코드 계약과 실제 운영 핵심 흐름을 끊지 않기 위한 작업이다. P1은 공개 상태를 재현·관찰하고 제품 가설 및 수집을 제한적으로 검증하기 위한 작업이다. P2는 M0 결과와 명시적 착수 결정을 선행 조건으로 하는 신규 기능이다. P3는 활성화 여부가 별도인 확장으로, M0 Core의 완료 판정을 대신하지 않는다.
